# CageLedger UI/UX 系统优化

本任务由用户授权完成展示层优化、逐模块验证、提交推送及整体验收后的集成与发布。基线为 `2e896a4`，版本 `1.31.11` / Build 280；开始时工作区干净，Gitea `main` 与 `beta` 均位于该提交。

## 范围与分支

- 开发分支统一为 `beta`，沿用仓库的长期分支模型；验收后通过 `rc` 集成到 `main`。
- Gitea 默认分支为 `main`，当前没有分支保护规则。仓库仅有手动触发的 Mac ARM64 备用工作流；普通 push/tag 不触发自动构建、发布或部署。每次模块推送回读远端提交，最终使用云端受管发布流程。
- 保持业务、权限、请求、值类型、筛选分页、批量范围、表单生命周期、确认与打印/导出契约。现有权限回退、兼容 API 和未接入历史组件不重写。
- 依赖保持锁文件版本：Ant Design 6.5.2；复用 `visual-system.mjs`、AntdProvider、CommandBar、Modal/Drawer 和现有数据层。
- 实际入口共 31 个工作台 View，另覆盖门户、登录、公开扫码及已有错误页。下表按依赖顺序推进；符合规范的页面也记录验收。
