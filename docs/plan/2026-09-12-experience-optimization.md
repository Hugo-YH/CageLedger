# 性能与交互体验优化任务（复核轮）

状态：已完成。目标模式下完成全部实施与验收。本轮以当前工作区为基线，保留此前未提交成果，前轮记录见 [性能与统一交互](2026-09-12-performance-ui.md)、[Ant Design 审查](2026-09-12-ant-design-system-audit.md) 和 [公共工具栏](2026-09-12-workspace-command-bar.md)。

## 目标与边界

提升操作的即时反馈、数据加载连续性和同类页面的一致性；依据实际代码、慢请求场景、带数据页面和前后测量决定改动，不为已有正常交互追加装饰动画。保留 Ant Design 语义 Token、32px 默认控件、8px 操作间距、16px 区域间距、操作主次及已确认的按场景吸顶规则。

数据由 TanStack Query 管理，局部草稿在页面保留；首次加载提供结构占位，刷新显示非阻塞提示，失败提供准确说明和重试。不能用空列表冒充加载失败，也不能让刷新或动效移除可操作控件。保存、上传、出具和导出显示真实进行中状态并防重复，成功与错误清楚区分。

仅优化性能与交互。权限、检疫业务口径、结算计算、报告内容和打印版式不变；不改用户运行数据，不提交、推送或发布。测试写入使用独立临时 SQLite；已有服务只有核实为隔离实例后才复用。

## 验证方法

- 前后使用相同构造数据与相同查询参数，记录规模、结果一致性、扫描或查询次数及耗时中位数。标准 benchmark 与隔离服务性能历史用于核查跨域影响；本机结果不作为生产 SLA。
- 在隔离浏览器延迟或失败对应请求，核对首次骨架、刷新旧数据、重试、草稿与焦点、重复点击和真实提交对象。故障解除后验证恢复。
- 视口为 1440×900、1180×900、760×900、844×390；公共占位及触屏另测 390×844。保留截图、控件高度、间距、最小宽度、overflow、position、z-index 等 computed style。
- 核对默认、焦点、禁用、加载、错误、重试、长文本；减少动画不依赖动画结束事件，不阻碍筛选、日期、弹窗及键盘操作。
- 运行受影响单元／API／浏览器回归，最终执行 Node 22 的 `npm run check`、构建和 `git diff --check`。最终检查由主任务集中运行，避免多组重复全量检查。
- 清单完成和验证证据齐备才结束目标；如存在真实设备或生产环境未验证项，交付中明确说明。

## 结果记录

### 性能

使用相同隔离数据和参数交替测量 5 轮，完整响应等价；基线为 `ef2a9c9` 中相关读逻辑。没有修改统计口径或数据库结构。

| 场景           | 规模                               | 优化前中位数 | 优化后中位数 | SQL 数变化 |
| -------------- | ---------------------------------- | ------------ | ------------ | ---------- |
| 检测详情       | 3 个检测，每个 200 样本 × 100 项目 | 369.68ms     | 16.98ms      | 8 → 8      |
| 单供应商历史   | 600 批次、1800 检测、60 供应商     | 140.46ms     | 12.32ms      | 602 → 11   |
| 到货日期无匹配 | 同上                               | 142.43ms     | 10.34ms      | 602 → 1    |
| 全供应商历史   | 同上                               | 213.40ms     | 211.88ms     | 602 → 602  |

两组独立服务在同一 60 秒采样窗各执行 32 个请求，HTTP P95 从 328.9ms 降至 24.7ms，数据库操作数 12522 → 702，慢请求及锁错误均为 0。SQLite P95 为 0.0ms → 0.5ms：大量近零查询被省去后样本分布改变，不作为单条 SQL 变慢的结论。本机结果不等同于生产响应承诺。

基准脚本为 `scripts/benchmark_quarantine_reads.py`；结果和两组性能历史在 `tmp/quarantine-read-performance-20260912/`，标准 benchmark 日志在 `/tmp/cageledger-experience-benchmark.log`。
