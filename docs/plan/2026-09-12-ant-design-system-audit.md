# 全系统 Ant Design 视觉与交互审查

状态：已完成。当前目标独立于上一轮性能优化；不能以 CLI 零告警或单个页面通过替代全系统验收。

## 依据与完成条件

使用项目安装的 `@ant-design/cli 6.6.0`、`antd 6.5.2`。已执行 `design.md`、`usage`、`doctor`、`lint`，原始结果保存在 `tmp/antd-system-audit/`。官方链接读取失败时，使用 CLI 返回的完整 design.md（设计默认值与主题定制规则），结合仓库 `antd-design-language.md`。

1. 清楚区分页面导航、记录选择、主操作、辅助操作及危险操作；同一决策组只保留一个主操作。
2. 同组控件使用 32px 默认高度；24px 紧凑行内操作与40px强调操作只在明确场景使用；容器6/8px圆角、4px间距网格、14px正文及400/600字重。
3. 普通标题和工具栏不遮挡正文；吸顶必须显式选择并验证短视口；单一滚动所有者，输入、下拉、长文本与弹窗均可达。
4. 共用组件由唯一样式层管理；颜色与层级通过 Ant Token；清除相互覆盖的遗留布局规则。
5. 从菜单进入全部业务模块，检查首屏、滚动、空态、真实结构数据、编辑／详情／确认和错误反馈，覆盖1440、1180、760和844×390，并补充390px触屏及深色／减少动态效果。
6. 保存逐页问题、修复和截图／computed style证据；运行项目指定 Node22 的检查、构建和相应全量浏览器回归。数据、权限、Word及打印业务保持原有语义。

## 页面与状态覆盖

清点依据：`workspaceNavigation.ts`、`ReactWorkspace.tsx`、业务子面板与弹窗组件。以下每项都需要实际页面证据，允许复用共同组件的尺寸／状态证据，但不跳过页面布局复核。

- 总览、登录、项目门户、公开扫码、手机扫码。
- 预约消息识别、待接收批次、预览打印／接收确认。
- 检疫批次（待检疫列表／批次列表／新建编辑）、寄生虫／ELISA／PCR（批次／详情／填写）、检疫报告（列表／供应商历史）。
- 笼位管理、待进驻／预留／在住记录、笼位编辑与动物详情。
- 巡检录入、异常列表、记录列表、标准目录／编辑／发布／版本历史。
- 数量统计表录入／历史／编辑预览，结算列表／预览／批量操作，汇总导出。
- 单据跟踪当前启用的结算流程，以及登记、撤回、详情、归档确认等弹窗。应收／报销／对账／历史旧面板当前未被 WorkflowCenterView 引用，仅做静态核对，不计入实际菜单验收。
- 账号、房间／笼架编辑、数据维护、系统状态、审计日志。

测试仅使用隔离数据。既有未跟踪软件著作权资料保持原样；提交／推送／发布不属于本次授权。
