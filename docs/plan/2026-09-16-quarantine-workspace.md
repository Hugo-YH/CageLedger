# 检疫管理工作台重设计

日期：2026-09-16。范围：检疫批次、寄生虫、ELISA、PCR、报告与供应商历史。在现有 beta 工作区实现，用户已追加授权提交并推送代码；发布和运行数据改写不在本次范围内。

## 目标和依据

登记与管理采用 Ant Design 业务界面，PDF 独立沿用既有历史模板。参考 [LabKey 检测数据管理](https://www.labkey.org/limshelp/wiki-page.view?name=manageAssayData) 的记录列表、样本关联、版本追踪，以及 [Benchling](https://www.benchling.com/features) 的样本与结果关联；不引入其权限或医学判定规则。

现状：检测页面重复批次列表、报告页并非报告台账、编辑页模仿纸张且样本横向扩张、离开编辑缺乏未保存保护。既有版本冲突、服务端校验、报告快照及审计应保留。

- [x] P0 / L：Ant 登记编辑器。基础信息、样本、项目、结果、原始资料分区；每个样本一行；完整保留原始字段。清理纸张样式。保存失败保留草稿、并发冲突不可覆盖、离开需确认。

依赖：列表 API → 工作列表；编辑器与 API 可并行；整体验收依赖全部实现。主代理负责 API、安全边界和最终审查；一个 Terra 子代理负责编辑器，文件范围互斥。不更改模板、既有数据或现行权限规则。
