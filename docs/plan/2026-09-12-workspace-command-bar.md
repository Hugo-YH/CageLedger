# 公共工具栏系统化接入

## 目标与规则

按用户确认统一顶部操作区域：编辑和选中后的批量操作吸顶；手机仍在顶部，全部按钮直显换行；筛选、工作对象变化清选择，翻页、页大小和排序保留。数据库、权限、报告及打印内容沿用现有规则。实现契约见 [UI 交互系统](../contracts/ui-interaction-system.md)。
