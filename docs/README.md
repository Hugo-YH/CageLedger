# 文档与维护入口

当前事实从 [当前实现与兼容边界](contracts/current-baseline.md) 开始核对。使用和部署说明的源文件在 [`wiki/`](../wiki/Home.md)，线上由 `/docs/` 提供；不要把整个 `docs/` 目录当成当前任务清单。

| 位置                                                                         | 内容与使用边界                                                             |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [`contracts/`](contracts/documentation-system.md)                            | 当前模块、业务写入、UI、测试、文档和交付规则；按任务读取                   |
| [`archives/`](archives/README.md)                                            | 历史计划、决策与验收，保留原版本、证据与未完成项；不是当前任务或授权       |
| `plan/`、`progress/`                                                         | 既有历史路径的兼容索引；新任务只在确需交接时建立范围明确的记录             |
| `analysis/`                                                                  | 专项分析、资料与历史验收；以各文件明确的日期和代码基线解释，不替代当前实现 |
| `templates/`                                                                 | 按需使用的记录模板，不要求所有改动填写                                     |
| [`PERFORMANCE_TODO.md`](PERFORMANCE_TODO.md)、[`DEMO_PREP.md`](DEMO_PREP.md) | 历史清单与演示记录的索引，不证明当前环境存在相应数据或待办                 |

当前分支、提交和版本从实际 Git 与 `package.json` 读取；验证矩阵只维护在 [测试策略](contracts/testing-strategy.md)。提交、推送、制品发布与生产部署分别遵守当前授权，历史记录不能改变其边界。
