# CageLedger Ant Design UI 重构：风险评估

| 风险                             | 影响                           | 控制措施                                                          | 验收                                                 |
| -------------------------------- | ------------------------------ | ----------------------------------------------------------------- | ---------------------------------------------------- |
| 旧 CSS 级联覆盖 Ant 样式         | 表单、表格和移动端视觉继续混搭 | 分批删除领域覆盖；每次迁移只保留对应 feature 的专用样式           | 浅色/深色截图与 CSS 契约检查                         |
| 录入控件迁移导致输入失焦         | 数量统计表录入效率下降         | 数量网格保留局部 state、Ant `Input`/`Select` 与定向 Tab 顺序      | 高频输入 E2E 与手工录入验证                          |
| 表格替换丢失服务端筛选和跨页选择 | 批量操作范围错误               | `DataTable` 适配层持有 rowSelection、query 参数和 selection scope | API、分页、跨页选择与批量操作 E2E                    |
| 暗色主题覆盖不足                 | 文字、边界、浮层不可读         | 全部颜色经 ConfigProvider 和语义 Token；移除硬编码浅色背景        | 深色截图与 Axe 对比度检查                            |
| 移动端桌面规则泄漏               | 375px 页面横向溢出或布局裁剪   | 移动端以 antd-mobile 容器为边界；禁用 legacy 面板最小宽度         | 760px、手机横屏 Playwright 基线                      |
| 弹窗替换破坏焦点与确认流程       | 键盘路径和危险操作风险         | 统一 `Modal`、`Drawer`、`Popconfirm` 与 `App.useApp()`            | 焦点恢复、Escape、确认与 screen-reader 检查          |
| 全量一次迁移回归范围过大         | 业务流程难以定位故障           | 基础系统、列表、表单、领域页面分阶段合并；每阶段可部署            | `npm run check`、API smoke、领域 E2E、PDF/Excel 回归 |
