# 结算预览工具栏响应式整改

- 日期：2026-08-23
- 范围：结算单预览弹窗的伦理号与操作按钮布局
- 样式所有者：`src/styles/features/billing.css`

## 问题与处理

原工具栏使用单行省略文本，并与操作按钮共享一行；在中等视口下，伦理号的可读空间会被按钮组压缩。整改后增加明确的“伦理号”标签，伦理号允许自然换行；在 `1180px` 及以下改为上下分区，按钮组保持完整。

- `npm run check:style-ownership`：通过。
- Playwright 长伦理号用例：`1098 × 652` 下无截断、越界或重叠。
- 浏览器实测：`1362 × 652`、`1180 × 700`、`760 × 700`、`844 × 390` 均无页面横向溢出、工具栏越界、文字截断或按钮遮挡；4 个操作按钮均可见。
- 控制台：无 error 或 warning。
