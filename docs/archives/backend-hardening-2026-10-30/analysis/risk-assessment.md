# 风险与修复取舍

| 风险                 | 已有证据                            | 处理                                       |
| -------------------- | ----------------------------------- | ------------------------------------------ |
| 下载头注入           | multipart RFC2231可产生含CRLF的名称 | 统一出口清理，保留常见名称与内容           |
| AI授权头跨源转发     | 默认urllib跳转会携带Authorization   | 禁止上游跳转，响应体有界，POST不重试       |
| PDF失效竞态          | Event强制交错后旧文件仍可落盘       | 发布与失效原子化，覆盖同步／后台及全量失效 |
| 报销详情N+1          | 10行20分摊需73条SQL                 | 批量只读投影，原字段／异常／排序等价       |
| 全局缓存并发与失效   | get/load/set之间无版本保护          | 增加显式世代校验与可安全合并的只读重建     |
| 任务、连接、文件资源 | 队列无上限、附件提交失败清理待核查  | 测量后设置有界资源，保留任务状态与原事务   |

账单金额、减免、共同负责人分组、权限模型、数量表多张规则及历史数据不得因优化改变。不为统一外观改旧响应／错误码或增加不兼容分页；不删除无测量依据的索引。新增索引必须证明查询收益并可独立回滚；异常数据不自动修复。
