# 风险与验收证据

## 高优先级证据

- `uiStorage.ts` 的 catch 内再次调用未保护的 removeItem，启动清理也未保护；浏览器拒绝 Storage 时可直接白屏。
- `AntdProvider.tsx` 自行读取系统主题但未订阅变更；CSS 主题另有监听，二者可能分离。深色主题强制使用浅色文字和按钮 token。
- `DataTable.tsx` 列宽可能为字符串却参与加法，忽略调用方 components/size，切换 resizeKey 可覆盖另一表格配置；resize 每次同步写存储。
- 总览待办存在两个不属于 WorkspaceView 的强制断言导航值。
- 多个保存/删除处理未捕获 mutateAsync 失败；部分预览在请求失败时保持 Skeleton。
- 异步详情和伦理匹配缺少过期响应校验；批量写入存在逐项失效刷新。

## 风险控制

| 风险                     | 控制方式                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------- |
| 业务与权限回归           | 不改协议/数据库/结算口径；已有全量 E2E、API 冒烟，管理员与房间管理员分别验证            |
| 取消查询改变共享缓存行为 | Query key 保持不变，signal 只接入只读 fetch，写入不取消；测试快速切换与共享订阅         |
| 分页占位旧数据被误操作   | 翻页期间保留可见反馈，旧页不能当新页批量操作；筛选/选择语义保持明确                     |
| 公共表格影响全系统       | 表格特性矩阵测试（数字/字符串列宽、分组、fixed、selection、virtual、自定义 components） |
| 主题与 Portal 不同步     | 系统/浅色/深色与减少动效组合验证；读取实际 computed style                               |
| 浏览器空白问题误归因     | 既有“内容拦截器导致空白”未经隔离验证，不作为结论；补启动错误与生产构建验收              |
| 视觉测试假阳性           | 覆盖 1440/1200/1180/992/768/760/390/844×390；截图、溢出与控件高度断言                   |
