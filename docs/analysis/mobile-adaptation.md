# CageLedger 移动端业务页 antd-mobile 适配准备

状态：`LOCAL_ONLY`。分支 `codex/ant-design-ui-refactor`（v1.0.0-beta5 之后），对应 ant-design 收敛计划 Phase 4。

## 现状基线

- `antd-mobile@5.42.3` 已安装，`es/global/global.css` 已引入，`ConfigProvider` 移动端外壳已移除（移动组件使用默认主题）。
- 移动端导航已就绪：`MobileNavigation` 使用 antd-mobile `TabBar` + `Popup` + `List`，760px 以下挂载，Tab 直达 + “更多”弹层含项目门户、各业务子菜单、刷新与退出。
- 业务页面仍是桌面 antd 布局：760px 断点下只有少量 CSS 收缩和表格 `scroll={{ x: 760 }}`，表单、弹窗、列表均未使用 antd-mobile 组件。
- 桌面壳层（`Layout.Sider` + `Menu`）在 760px 以下隐藏，内容区由 `workspace-body` 承担。

## 适配目标

760px 以下业务页面改为 antd-mobile 容器与交互：

1. 页面内容单列化，进入页面即使用 antd-mobile 组件（`List`、`Form`、`Selector`、`Dialog`、`Toast`、`Button`、`SafeArea`），桌面壳层样式不跨断点泄漏。
2. 高频移动场景优先：动物巡检（现场使用）、笼卡接收与扫描、数量统计表录入。
3. 低频管理页（系统设置、账号、日志、数据管理）保留桌面 antd 组件，仅做单列化与横向滚动，不引入双组件改造。
4. 表格统一 `scroll={{ x: ... }}` 横向滚动 + 固定关键列，移动端不重排表格结构。
5. 弹窗统一为 antd-mobile `Popup`/`Dialog`（760px 以下），复用现有 `ui/` 适配层扩展移动端变体。

## 页面清单与优先级

| 优先级 | 页面                        | 移动端形态                                   | 说明                           |
| ------ | --------------------------- | -------------------------------------------- | ------------------------------ |
| P0     | 动物巡检（录入/记录/标准）  | antd-mobile 表单 + 评分卡片                  | 现场录入主场景，移动端收益最大 |
| P0     | 笼卡接收与二维码扫描        | antd-mobile 表单 + 扫描入口                  | 仓库现场操作                   |
| P1     | 数量统计表录入              | antd-mobile 单列表单 + 31 行网格保持专用 DOM | 表格网格保留，头部字段单列化   |

| P2     | 笼位图                      | 保持虚拟化 + 触控槽位                        | 业务专用 DOM，仅优化触控间距   |
| P2     | 流程中心 / 报销             | 单列化 + 现有 antd 表单                      | 管理场景，桌面优先             |

## 实施策略

- 在 `ui/` 适配层新增移动端变体：`useIsMobileLayout()`（760px 匹配，已在 ReactWorkspace 使用）抽取为共享 hook；`ActionButton`、`Dialog` 增加移动端渲染分支。
- 每个 P0/P1 页面按“容器单列化 → 表单控件替换 → 弹窗替换 → 表格滚动”四步推进，每页独立提交。
- 移动端与桌面共用数据层与领域逻辑，只换表现层组件。
- 键盘输入场景（数量录入、巡检评分）保持局部 state 与防抖，避免整页重渲染。

## 验收标准

- 760px、390px、430px 视口下：无横向溢出、表单可完整操作、导航与返回可用、桌面壳层样式不泄漏。
- 巡检录入在手机视口完成一次完整保存；笼卡接收完成一次识别；数量统计表完成一次保存。
- reduced-motion 下动效关闭；Axe 移动视口无严重违规。
- 桌面视口回归：现有 19 条 e2e 全部通过，新增移动视口用例覆盖 P0 页面。

## 风险与对策

| 风险                             | 对策                                                            |
| -------------------------------- | --------------------------------------------------------------- |
| antd 与 antd-mobile 双主题不一致 | 移动端组件使用默认主题并复用语义 token；视觉验收覆盖 760px 截图 |
| 移动端软键盘遮挡输入             | 页面滚动容器 + antd-mobile 组件默认处理；巡检/数量录入专项验证  |
| 表格横向滚动与选择列固定冲突     | 固定选择列 + 数据列滚动，视觉验收                               |
| 双组件维护成本                   | P0/P1 页面组件化替换，P2/P3 仅 CSS 单列化，控制改造面           |
