# 异常动物（大动物）评估：首版目录草案（沿用小鼠结构）

## 目的与使用边界

本草案用于将现场可观察到的异常表现统一分类，适用于当前照片涉及的猴、兔、普通级豚鼠和犬。它是巡检与升级处置的记录工具，不代替兽医诊断、治疗方案或伦理终点判断。

- 正式录入使用“正常 / 异常”结论；异常时选择异常类型、填写现场说明并可关联照片。
- 文件名和图例描述仅记录可见表现；带有“原标记”的内容保留收集时的线索，须由兽医确认后才可作为诊断。
- 同一照片可关联一个主条目和多个辅助条目；首版以主条目归档，避免重复存放。

## 目录结构与异常类型

目录沿用现有“异常动物（小鼠）评估”的由整体到局部的结构；文件夹即为当前图片的正式归类。未收集到图片的分类也保留，后续直接补充参考图即可。为适配大动物，保留了小鼠的一级区域，但将不适用的生殖细项改为按物种启用。

## 兽医建议与升级规则（草案）

本节是巡检现场的初步处置建议，不是诊断或处方。药物、镇痛、抗感染、补液、强制饲喂、清创缝合、复位、固定、隔离时长和安乐死决定，均应由本单位兽医依据批准的动物实验方案、福利伦理要求和临床检查确定。对于社会性动物，只有在继续同笼会造成攻击、污染、误伤或妨碍治疗时，才在兽医指导下临时隔离，并尽量保持视觉、听觉或嗅觉接触。

## 发布前需要兽医确认的事项

1. 三级时效的最终判定口径：立即联系兽医、当班/当日兽医评估、记录并加强观察；是否需要细分 24–48 小时复查由本单位兽医确认。
2. 物种专属阈值：尤其是兔的胃肠异常/头倾斜、非人灵长类术后眼部表现、豚鼠采食下降与犬的恐惧行为。
3. 正常对照、轻度和重度对照照片的最小样本量；当前仅有异常例图，不能单独构成严重度标准。
4. 哪些表现须强制记录体重、采食饮水、粪便、体温或实验/手术日期。

## 参考依据

- [GB/T 42011-2022《实验动物 福利通则》](https://std.samr.gov.cn/gb/search/gbDetailed?id=F159DFC2A79D47EFE05397BE0A0AF334)：当前有效的实验动物福利通用国家标准。
- [GB/T 35892-2018《实验动物 福利伦理审查指南》](https://openstd.samr.gov.cn/bzgk/gb/newGbInfo?hcno=9BA619057D5C13103622A10FF4BA5D14)：用于福利伦理审查、疼痛和痛苦减轻等原则性要求。
- [科技部《关于善待实验动物的指导性意见》](https://www.most.gov.cn/xxgk/xinxifenlei/fdzdgknr/fgzc/gfxwj/gfxwj2010before/201712/t20171222_137025.html)：要求避免不必要的伤害、惊恐、疾病和疼痛，并提供良好管理与照料。
- [OLAW《Guide for the Care and Use of Laboratory Animals》](https://olaw.nih.gov/sites/default/files/Guide-for-the-Care-and-Use-of-Laboratory-Animals.pdf)：用于兽医照护、疼痛/痛苦识别、术后监测和仁慈终点的通用原则。
- [NC3Rs：Humane endpoints](https://nc3rs.org.uk/3rs-resources/humane-endpoints)：用于建立提前干预的清晰判据和基于评分表的持续观察。
- [NC3Rs：Macaque welfare assessment](https://macaques.nc3rs.org.uk/welfare-assessment)：用于非人灵长类的行为、临床和生理综合评估及个体基线比较。
- [UBC：Guidelines on Monitoring and Medical Records of Animals Used for Research](https://animalcare.ubc.ca/sites/default/files/documents/UBC%20ACC%20Policy%20017%20Guidelines%20on%20Monitoring%20and%20Medical%20Records%20of%20Animals%20used%20for%20Research%2C%20Teaching%20April%202018.pdf)：用于神经异常、运动障碍、伤口和术后观察项目。
- [University of Michigan：兔麻醉与镇痛指南](https://az.research.umich.edu/animalcare/guidelines/guidelines-anesthesia-and-analgesia-rabbits)及[豚鼠麻醉与镇痛指南](https://az.research.umich.edu/animalcare/guidelines/guidelines-anesthesia-and-analgesia-guinea-pigs/)：用于兔和豚鼠疼痛、采食下降、活动减少、异常姿势等观察指标。

以上资料用于形成通用巡检和升级原则；本草案不能替代本单位兽医签发的 SOP、批准的动物实验方案、项目特异性仁慈终点或生物安全程序。
