# 技术服务计费验收记录

日期：2026-10-14。分支：`beta`。本次为开发验收，不包含提交、推送、正式发布或生产数据写入。

## 功能与业务证据

- 已实现录入技术服务明细、已保存技术服务明细两个独立页面，技术服务结算并入共用结算列表，复用IACUC数据及现有单据跟踪、报销应收和核销能力。
- 院内大动物滴眼30元／眼，四日数量2、2、4、2，在保存、详情、结算预览和汇总导出中保持4个服务日、10眼、300元。
- 相同组合维护同一明细表；创建重复请求不重复审计，删除后旧请求不恢复记录，版本缺失或过期返回409。
- 普通编辑保留收费快照及项目信息；服务数量由服务端校验，金额按十进制逐行取分，页面计算与服务端一致。
- 同月同负责人两类账单使用独立业务键和编号。技术服务已发起时源明细只读，撤回后恢复维护能力。
- 真实API验证同名不同账号的撤回资格、房间管理员登记权限、未授权锁定拒绝、管理员锁定及解锁后撤回；审计与数据库状态一致。
- 共用报销单可分别核销300元技术服务费与55元饲养费，两类应收不碰撞、不重复累加。
- 技术服务独有月份可以导出；费用按对应伦理及设施归属，技术服务列为S列，原饲养费G/H/I列及公式语义保留。

## UI 与布局

三个页面沿用饲养费工作区的顶部CommandBar、panel分组表单、DataTable及Pager。保存操作位于顶部；两张列表通过共用FilterableColumnTitle在列头显示漏斗，不保留额外的月份／搜索输入栏。筛选支持多选、清空、应用、高亮和分页重置，排序与筛选均由服务端在分页前处理。选项统计全部记录，排除本列已选条件、保留其他列条件。结算伦理筛选保留整张负责人结算金额，已发起单据的金额筛选读取账单快照。已保存列表的“预览、编辑、删除”采用相同的64px按钮、8px间距、预览浅蓝／编辑蓝色主按钮／删除危险色。预览为独立只读弹窗，编辑与结算预览保留现有业务操作。样式唯一来源为 `src/styles/features/technical-services.css`，已登记到样式归属及导入顺序。

移动端及短横屏复用 `src/theme/visual-system.mjs` 的同一主题工厂，不定义独立调色或控件尺度。切换视口保留表单实例和草稿。
