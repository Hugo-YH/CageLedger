# 共享性能约定

适用于共享缓存、写后刷新、按目标读取、工作台渲染与文档处理。金额、权限、版本冲突、历史快照和审计继续遵守现有业务契约。

## 缓存与读取

- 写事务不使用或发布进程共享缓存，不等待只读构建锁。只读 miss 按精确键合并，热命中不等待构建；按键锁在最后一个使用者退出时回收。
- 填充前捕获版本。发布时核对读取后发生的精确键及前缀失效，沿用写入入口已经列明的依赖集合；无关失效不丢弃在途填充。历史最多保留512次，超过窗口的旧读取保守拒绝。提交后的失效仍保留，不能以取消全局保护替代依赖检查。
- 已确定不能发布的值跳过体积估算，估算后仍在发布锁内重新检查版本。容量、TTL和空值语义不变。
- 单目标伦理查询复用批量 `applications_for_iacucs`，从原payload取编号并保留标准化后首条匹配；只解码命中记录，写事务内不发布缓存。涉及同一PI减免时必须包含全部实际依赖，不把当前表单编号误当全部计费来源。
- 扫码只读取目标批次及关联任务、占用、笼位、笼架、房间与伦理；保留历史编号、匹配优先级和公开字段。初始化摘要使用原字段投影；完整与房间入口继续保留原响应。
- 字段投影对重复相关键、BLOB编码和旧JSON形状回退原解析，不用可能过期的结构化列替代原payload，不回填或改写原数据。

## 前端协调

- 完整保存响应在检查会话、取消旧目标读取后回写详情，再精准刷新实际依赖；只适用于完整目标响应。部分响应继续由唯一owner读取最终详情。
- 核销等写操作和读取失败分别反馈，重试读取不重放POST。详情由组件负责最终刷新时，hook仅标该目标stale，其他真实依赖正常失效。
- 工作台菜单、侧栏和页脚状态与业务页渲染隔离；稳定导航回调，不重挂载页面清草稿。权限、主题、未保存导航守卫和滚动恢复保持响应。

## 文档资源预算

Chromium、LibreOffice及合格证PDF处理共用 `DOCUMENT_WORK`，只在实际执行转换时取得名额。提交任务、等待另一工作线程和普通HTTP/SQLite读取不取得重任务名额；同线程同步嵌套复用已有名额。各转换器原局部限制、失败响应和转换时限继续保留。

| 环境变量                       | 默认值      | 含义                           |
| ------------------------------ | ----------- | ------------------------------ |
| `CAGELEDGER_HEAVY_MAX_WORKERS` | `1`         | 同时执行的重文档任务，范围1–8  |
| `CAGELEDGER_HTTP_MAX_WORKERS`  | `32`        | 原HTTP连接处理上限             |
| `CAGELEDGER_SQLITE_CACHE_KIB`  | `80000`     | 每连接页缓存建议上限，按需使用 |
| `CAGELEDGER_SQLITE_MMAP_BYTES` | `268435456` | 每连接mmap窗口，0表示关闭      |

两份Compose均透传这些配置。DS223的后续调优先观察混合负载下的内存、HTTP P95/503、锁错误与等待，再调整配额；不能将缓存或mmap配置值乘连接数当作实际内存占用。云端隔离验证不代表NAS实测。

PDF文件目录枚举、排序和批量清理不占用任务元数据锁；源版本、原子发布、容量TTL、任务所有权及失效后不能下载旧任务内容的边界不变。统计复用维护快照，并在本进程发布/删除时增量更新。

## 指标与验收

管理员环境快照及性能历史增加可选 `stages` 与 `documentWork`。旧响应兼容；固定阶段仅包含缓存估算/等待、结果取数、解码、响应编码/压缩、文档资源等待和PDF维护。每阶段最多保留512个延迟样本；累计次数、行数和字节数只为运维指标，不包含业务内容、身份、参数、路径或SQL。SQLite原生execute指标保持原口径，fetch和decode独立展示，阶段P95不相加。

共享改动按实际影响运行并发缓存/双连接可见性、真实QueryClient请求计数、目标读模型等价、文档预算与文件维护竞态，以及代表性浏览器导航/扫码。性能对照使用相同隔离数据、请求窗口和原生HTTP/SQLite指标，核对原始业务与审计未改写。既有未受影响检查可复用，生产调参和发布另按授权执行。
