# CageLedger UI 颜色与状态

颜色唯一来源为 `src/theme/visual-system.mjs`。ConfigProvider 使用官方浅深算法，生成器输出 `brand-tokens.css`；`tokens.css` 保留业务语义别名，页面不另选颜色。`data-theme` 表示当前解析后的主题；跟随系统偏好继续保留。

## 基础与业务语义

| 用途             | 变量                                                                |
| ---------------- | ------------------------------------------------------------------- |
| 页面／内容／浮层 | `--bg`、`--surface`、`--surface-elevated`                           |
| 文字／说明       | `--text`、`--muted`、`--text-subtle`                                |
| 边界             | `--line`、`--card-border`                                           |
| 品牌与选中       | `--primary`、`--primary-text`、`--primary-control`、`--selection-*` |
| 成功／警示／错误 | `--success-*`、`--warning-*`、`--danger-*`                          |
| 预留／财务类别   | `--reserved-*`、`--finance-*`                                       |
| 信息／待办       | `--info-*`、`--todo-*`                                              |
| 浮层／焦点       | `--shadow-pop`、`--focus-ring*`                                     |

官方蓝为主色种子，白字按钮和正文链接使用集中配置的官方对比色阶。正常文字在实际浅深背景上的对比度至少 4.5:1；状态同时提供文字或图标。禁用控件仍保留标签和原因说明。

## 操作层级

每个操作区最多一个主按钮；常规操作默认，辅助操作 text/link，危险操作 danger 并保留确认。返回、查询、重置、保存保持可见；明确低频动作进入“更多”，行内最多直接展示两个常用动作。主动作最后排列。

Hover 和 active 使用官方颜色反馈，控件位置、大小保持稳定。焦点可见、键盘可达；loading 来自真实业务状态并防止重复执行，不让动画承担状态推进。

## 表格与表单

- 表头与固定列使用不透明背景；hover 中性，选中连续浅色，颜色不作为唯一状态标识。
- 数字使用等宽数码并对齐；长文字保留可查详情；专用矩阵在容器内滚动，不能撑宽工作区。
- 输入、选择、日期按同一尺寸 Token 对齐，宽度填满所属网格列。只读信息优先文本、Descriptions 或复制字段。
- 校验错误与提交失败使用错误语义；可以继续的风险使用警示语义。错误定位为吸顶栏预留空间。
- 深浅主题、后台刷新、响应式变化不能清空草稿或重置焦点。

## 浮层与动效

Tooltip、Popover、Modal、Drawer 使用 Ant 定位和层级机制，不在业务卡片内手工定位。保留焦点恢复、Escape、边界避让与危险确认。动画使用主题的官方命名 Token；减少动画时立即转换业务状态，扫码冻结、框选和校正保持可用。

尺寸、字体与间距见 [视觉语言](antd-design-language.md)，样式归属见 [样式契约](style-ownership.md)。不采用药丸形按钮或自定义逐页曲线。纸质打印和报告继续由专属样式管理。

## 维护与验收

优先复用语义 Token；新增业务映射先进入唯一主题与生成器，覆盖浅深主题，再执行 `node scripts/generate_theme.mjs`。门禁用 `--check` 验证生成结果，禁止手改生成 CSS。检查实际默认、hover、focus、disabled、loading、错误、选中状态，静态门禁不替代浏览器对比度和响应式验证。
