# CageLedger UI 交互系统

本规范约束工作区、导航、浮层、弹窗、列表和异步反馈的统一交互。业务页面沿用既有 API、权限、数据与导出规则。

## 工作区结构

每个业务首页使用 `WorkspaceHeader + workspace-toolbar + panel` 结构。标题栏展示业务域、页面标题、状态和必要摘要；主操作放入紧凑命令栏；页面内容按表单、列表、详情与空态分区。

## 导航

- 桌面端突出当前业务域与当前二级路径。
- 平板和移动端二级菜单使用底部 sheet，顶部显示业务域名称和关闭入口。
- 底部主导航仅展示高频一级入口，其他入口通过“更多”打开。
- 导航、菜单、弹窗关闭后焦点回到触发控件。

## 工具提示与浮层

- 一句辅助说明使用 `Tooltip`；复杂说明使用可关闭 popover 或弹窗。
- `Tooltip` 在上下左右四个方向中选择可用位置，并保持 12px 视口安全边距。
- 触发器位于窄屏或靠近边缘时，浮层随视口避让并在滚动、缩放和窗口变化时重定位。
- 工具提示使用 `z-index: 600`，浮层内容避开侧栏、底部导航和弹窗边界。
- 移动端帮助按钮支持点击打开，点击页面其他位置、按 Escape 或失焦关闭。

## 弹窗

- 弹窗头部包含标题和紧凑关闭按钮，正文独立滚动，操作栏固定在底部。
- 移动端弹窗以 bottom sheet 展示，保留安全区和最大高度。
- 异常登记、图例画廊和详情弹窗使用一致的焦点锁定、Escape 关闭和焦点恢复行为。

## 列表与任务反馈

- 列表表头、数字、状态与操作列采用稳定对齐；长文本采用两行截断并提供详情入口。
- 表格容器保留横向滚动与边界提示；表头可 sticky，操作列按页面需要固定。
- 保存、上传、导出、PDF 生成和核销通过页面内状态提示展示进行中、完成、失败和重试结果。

## 动效与可访问性

- 按压反馈使用 100-160ms 的 `transform`；小浮层使用 125-200ms 的透明度与位移动画；弹窗和折叠使用 200-240ms 的可逆过渡。
- `prefers-reduced-motion` 下将过渡压缩为即时反馈。
- 所有可交互控件具有可访问名称、可见焦点与键盘路径；状态反馈使用 `aria-live`；表单错误关联输入控件。
