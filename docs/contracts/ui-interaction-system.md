# CageLedger UI 交互系统

本规范约束工作区、导航、浮层、弹窗、列表和异步反馈的统一交互。业务页面沿用既有 API、权限、数据与导出规则。

## 工作区结构

每个业务首页使用 `WorkspaceHeader + CommandBar + Card` 结构。标题栏展示业务域、页面标题、状态和必要摘要；主操作放入紧凑命令栏；页面内容按表单、列表、详情与空态分区。操作栏从左到右保留范围摘要、辅助操作和唯一主操作；表格行操作使用紧凑按钮并保持固定顺序。

## 导航

- 桌面端突出当前业务域与当前二级路径。
- 平板和移动端二级菜单使用底部 sheet，顶部显示业务域名称和关闭入口。
- 底部主导航展示高频一级入口；当前业务域的二级路径通过可关闭 Sheet 展示。
- 导航、菜单、弹窗关闭后焦点回到触发控件。

## 工具提示与浮层

- 一句辅助说明使用 `HelpPopover` 或 Ant `Tooltip`；复杂说明使用可关闭 `Popover` 或 `Dialog`。
- `Tooltip` 在上下左右四个方向中选择可用位置，并保持 12px 视口安全边距。
- 触发器位于窄屏或靠近边缘时，浮层随视口避让并在滚动、缩放和窗口变化时重定位。
- 工具提示使用 `z-index: 600`，浮层内容避开侧栏、底部导航和弹窗边界。
- Portal Tooltip 使用 `visualViewport` 作为移动端可见边界，地址栏、软键盘和页面缩放变化后即时重定位。
- 移动端帮助按钮支持点击打开，点击页面其他位置、按 Escape 或失焦关闭。

## 弹窗

- 弹窗使用 `Dialog` 或 Ant `Modal`，头部包含标题和紧凑关闭按钮，正文独立滚动，操作栏固定在底部。
- 移动端弹窗以 bottom sheet 展示，保留安全区和最大高度。
- 异常登记、图例画廊和详情弹窗使用一致的焦点锁定、Escape 关闭和焦点恢复行为。

## 列表与任务反馈

- 列表表头、数字、状态与操作列采用稳定对齐；长文本采用两行截断并提供详情入口。
- 表格容器保留横向滚动与边界提示；表头可 sticky，操作列按页面需要固定。
- 保存、上传、导出、PDF 生成和核销通过页面内状态提示展示进行中、完成、失败和重试结果。

## 动效与可访问性

- 按压反馈使用 100-160ms 的 `transform`；小浮层使用 125-200ms 的透明度与位移动画；弹窗和折叠使用 200-240ms 的可逆过渡。
- 进入与退出使用 `--ease-out`，位置变换使用 `--ease-in-out`，移动端 Sheet 使用 `--ease-drawer`。高频导航、分页、筛选与表格更新保持即时响应。
- hover 反馈只在细指针设备启用。高频导航、分页、排序和输入使用即时状态更新，动效用于表面进入、展开收起、状态反馈和操作按压。
- `prefers-reduced-motion` 保留透明度与颜色反馈，移除位移、缩放和重复 keyframe。
- 所有可交互控件具有可访问名称、可见焦点与键盘路径；状态反馈使用 `aria-live`；表单错误关联输入控件。
