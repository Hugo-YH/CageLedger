# CageLedger UI 交互系统

本规范约束工作区、导航、浮层、弹窗、列表和异步反馈的统一交互。业务页面沿用既有 API、权限、数据与导出规则。

## 工作区结构

工作页面按范围与筛选、执行操作、正文分区；存在页面级操作时使用 `CommandBar`，正文按表单、列表、详情与空态组织。页面标题和状态摘要按业务需要保留，避免同一操作在标题、工具栏和正文重复出现。操作栏从左到右保留范围摘要、辅助操作和唯一主操作；表格行操作使用紧凑按钮并保持固定顺序。只读页面、扫码等专用界面不强加空工具栏；总览页保留 `dashboard-hero` 作为应用名称与版本标识。

## 公共工具栏

`CommandBar` 是工作区操作栏唯一基础组件；`WorkspaceToolbar` 是兼容入口并完整传递配置。禁止页面直接声明 `data-ui="workspace-toolbar"` 或另造吸顶副本。公共布局与定位归属 `components.css`。

- `context` 放当前对象、范围和已有状态；`filters` 独立在操作行上方，保持静态；`actions` 为辅助动作，`primaryAction` 为最后一个主动作。
- `selection` 提供 `count`、`onClear`、`pending`，统一展示已选数量、清空选择和进行中状态；业务动作和权限仍由页面提供。
- `sticky=true` 用于长表单编辑；`sticky="selection"` 用于批量操作；其余默认不吸顶。图形工作区有选择或预留任务时启用。一个滚动容器最多一条操作栏吸顶。
- 控件默认 32px，操作间距 8px，区域间距 16px；辅助在前、主动作在后，每组最多一个主按钮。所有适用按钮直接显示，窄屏换行，不收进“更多”；手机保持顶部。
- 可用高度不超过 500px，或操作栏高度超过可用高度的 25% 时取消吸顶。尺寸、缩放和 `visualViewport` 变化重新测量，普通滚动由 CSS 完成，不触发 React 滚动渲染。
- 实际滚动容器由公共行为设置 `scroll-padding-top`，为章节跳转和错误定位留白；页面不重复写固定顶部偏移。组件卸载或失去吸顶资格时恢复原值。
- 加载、失败、重试沿用实际业务状态；刷新保留操作栏。只含筛选的页面不渲染空操作框，局部表单和弹窗不强加页面工具栏。

批量选择以已生效筛选和当前工作范围为边界：翻页、页大小、排序保留选择；筛选应用、搜索生效、房间、笼架或数据范围改变时清空，有原选择时提示“范围已变化，已清空选择”。仅打开筛选或编辑未应用条件不清空。范围变化必须取消或作废旧全选请求；已发起任务使用提交时快照，不因后续选择变化而改动执行对象。

## 导航

- 桌面端突出当前业务域与当前二级路径。
- 平板和移动端二级菜单使用底部 sheet，顶部显示业务域名称和关闭入口。
- 底部主导航展示高频一级入口；当前业务域的二级路径通过可关闭 Sheet 展示。
- 导航、菜单、弹窗关闭后焦点回到触发控件。

## 工具提示与浮层

- 一句辅助说明使用 `HelpPopover` 或 Ant `Tooltip`；复杂说明使用可关闭 `Popover` 或 `Dialog`。
- `Tooltip` 在上下左右四个方向中选择可用位置，并保持 12px 视口安全边距。
- 触发器位于窄屏或靠近边缘时，浮层随视口避让并在滚动、缩放和窗口变化时重定位。
- 工具提示使用 `z-index: 600`，浮层内容避开侧栏、底部导航和弹窗边界。
- Portal Tooltip 使用 `visualViewport` 作为移动端可见边界，地址栏、软键盘和页面缩放变化后即时重定位。
- 移动端帮助按钮支持点击打开，点击页面其他位置、按 Escape 或失焦关闭。

## 弹窗

- 弹窗使用 `Dialog` 或 Ant `Modal`，头部包含标题和紧凑关闭按钮，正文独立滚动，操作栏固定在底部。
- 移动端弹窗以 bottom sheet 展示，保留安全区和最大高度。
- 异常登记、图例画廊和详情弹窗使用一致的焦点锁定、Escape 关闭和焦点恢复行为。

## 列表与任务反馈

- 列表表头、数字、状态与操作列采用稳定对齐；长文本采用两行截断并提供详情入口。
- 表格容器保留横向滚动与边界提示；表头可 sticky，操作列按页面需要固定。
- 首次加载使用共享骨架；筛选、分页和刷新保留现有结果，显示不遮挡控件的“正在更新”提示。错误需提供重试，禁止用空表掩盖失败。不同详情之间不共用旧数据。
- 保存、上传、导出、PDF 生成和核销通过页面内状态提示展示进行中、完成、失败和重试结果。

## 动效与可访问性

- 按压反馈使用 140ms 的 `transform`；小浮层使用 220ms 的透明度与位移动画；弹窗和折叠使用 280ms 的可逆过渡，均复用 Ant Design 官方缓动 Token。
- 进入与退出使用 `--ease-out`，位置变换使用 `--ease-in-out`，移动端 Sheet 使用 `--ease-drawer`。高频导航、分页、筛选与表格更新保持即时响应。
- hover 反馈只在细指针设备启用。高频导航、分页、排序和输入使用即时状态更新，动效用于表面进入、展开收起、状态反馈和操作按压。
- `prefers-reduced-motion` 保留透明度与颜色反馈，移除位移、缩放和重复 keyframe。
- 运行中切换减少动画或浅深主题，不得重挂载业务表单、清空草稿或丢失焦点；验证偏好双向切换。Ant 控件及其内部按钮、输入框由组件 Token 管理尺寸，原生控件兜底样式不得覆盖 Portal 或移动端 Ant 控件。
- 所有可交互控件具有可访问名称、可见焦点与键盘路径；状态反馈使用 `aria-live`；表单错误关联输入控件。
