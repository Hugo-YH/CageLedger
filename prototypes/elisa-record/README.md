# ELISA 报告式录入原型

访问开发服务器 `/prototypes/elisa-record/`。这是独立交互原型，使用 Ant Design 控件；五部分顺序与原报告保持一致，不要求填写界面与纸质版逐像素一致。

- 演示数据独立于系统数据库，不调用业务 API。
- “样”按实验组（样本编号）数量计算，“份”按各组已选来源数量相加，同一来源在不同组分别计数；不再手填原始份数，旧草稿中的手填值不参与计算。样本、项目与结果按稳定 ID 联动。
- 图片支持多个检测项目、图注和顺序调整。
- 结果仅阴性、阳性、可疑；空白不当作阴性。
- “保存演示草稿”保存在本浏览器 localStorage；图片为本地数据 URL。原型单张图片限 8MB，浏览器空间不足时明确提示。
- “报告预览”仅用于审阅交互，不提供正式 Word 导出或报告出具。

已验证：数量汇总、增删样本、修改项目名称后保留结果、图片多项目关联、本地保存恢复、只读预览。检查了 1440、1180、760、844（横屏）、390 像素视口，无页面横向溢出；宽表允许局部横向滚动。截图位于 `/tmp/elisa-prototype-qa/`。样式检查和 `git diff --check` 通过；原型 JSX 不在项目现有 ESLint 配置覆盖范围，已通过 Vite 与浏览器运行检查。
