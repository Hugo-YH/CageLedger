# 检疫Word模板基线

直接保留用户原Word的A4页面、页边距、字体、页眉页脚、标题块、横向样本表、试剂表、双栏图片区、横向结果表和签名栏。模板中的示例业务内容、日期、结果和图片已清空。生成器只填充内容槽，按原有行与列样式扩展。

多样本按模板容量分组；短结果表保留完整分组分页，避免Word将相邻表格自动合并后重复错误表头。去除浮动表格定位使增减项目后的章节继续按原顺序流动；报告编号、草稿标识和模板版本放在原页脚。重复的结果章节编号顺排为寄生虫4、ELISA5、PCR6。检测人及复核人保留原空白签名位置。PCR样本不超过6组使用20260903表，大样本使用20260827表。

模板版本：`quarantine-1`。ELISA小鼠Toxo/MYco对应关系依据同份模板试剂清单整理；重复章节编号按顺序生成；大鼠KPV保留原文。PCR项目同时参考20260903记录表中的鼠棒状杆菌。
