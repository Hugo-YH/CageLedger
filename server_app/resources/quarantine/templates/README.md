# 检疫Word模板基线

保留用户原Word的A4页面、页边距、字体、页眉页脚、标题块、横向样本表、试剂表、单栏或双栏图片区、横向结果表和签名栏。模板中的示例业务内容、日期、结果和图片已清空。生成器填充内容槽，按原有行与列样式扩展。

按样本量及ELISA图片数量选择历史版式：寄生虫使用5、6、7组样本原表；ELISA小鼠使用3、4、7组双栏图片区原表，只有一张图片时使用4或8组单栏原表；ELISA大鼠使用1或2组原表；PCR使用6、8、9组原表。超过最大容量时继续克隆行组、分组结果表；PCR大表的第二行组末格原本留缺，按该行组的实际容量填充。图片保留原表各列宽度及各槽位尺寸，按上传顺序等比缩放；后续行使用原模板对应行格式，超出后复用最后行组。

结果表按检测项目名称匹配；适用样本更多时选同份原表的宽表，未包含的新项目使用通用宽表。仅在同一项目拆成相邻表格时插入分隔段，避免Word自动合并表格；结果表和签名块保留必要的分页约束。去除浮动表格定位，使动态内容按原顺序流动。大标题及图例保留原文和自动编号，子项目沿用原表前缀（寄生虫4、ELISA4、PCR5）按实际项目顺序编号。检测人、复核人及签字日期留空；草稿标识追加到原页脚。

模板版本：`quarantine-3`，仅用于新生成的预览及报告，已出具文件保持归档原件。ELISA小鼠Toxo/MYco对应关系仍依据现有项目目录；历史同名项目的括号缩写差异仅用于定位版式，不覆盖录入的检测项目。大鼠KPV保留原文。各模板来源及原件SHA-256见 `manifest.json`，其中散列标识原始附件，不是清空内容后的模板文件。

回归覆盖页面及样式保留、样本和结果容量、项目重排、单栏图片、非等宽图片和各图片槽位尺寸；最终通过隔离的 LibreOffice Writer 配置转换为 PDF，下载接口只输出 PDF；DOCX 是内部模板中间件。验收检查实际 PDF 的分页、裁切及图文顺序，不能以 DOCX 结构测试代替 PDF 渲染检查。
