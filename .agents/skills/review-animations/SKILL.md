# 动效代码评审

只读评审用户指定的动效范围。核对真实触发场景、使用频率、缓动与时长、动画起点、快速重复操作、reduced-motion、触屏 hover 和性能。

具体技术参考见 [STANDARDS.md](STANDARDS.md) 对应条目。项目 Token 和无障碍契约优先；参考中的时长、曲线与设计偏好不是自动阻断条件。不要仅凭关键字或缺少某种动画就认定缺陷。

报告可定位的代码、用户影响、证据和建议；不能由静态代码判断的效果说明需实测。允许无发现，不默认否决，不强制固定表格或评分。混合代码评审中只负责动效部分，继续完成用户其余目标，不因本技能范围拒绝整个任务。
