# 动效机会分析

查看目标页面的状态变化与已有 Token，按频率、用途、时长和对输入的影响筛选候选。具体场景见 [candidates.md](references/candidates.md)。高频工作台通常只需少量反馈，不为凑数增加装饰。

报告候选位置、用途、建议行为与验证方式；区分实测证据和待验证假设。沿用项目 Token，尊重 reduced-motion，可关闭非必要动画。

仅要求分析时不改源码；用户同时要求实现时，在分析后继续完成被授权的修改与目标验收，不强制委派或停下来等待再次确认。
