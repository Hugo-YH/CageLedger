# 前端选库

先确认所需能力及 `package.json` 中的现有依赖。CageLedger 使用 Ant Design 与 TanStack，已有实现满足需求时继续使用，不把选库建议变成替换依赖的任务。

需要新能力时，查 [候选库](references/libraries.md) 对应类别，并核实当前版本、兼容性与维护状态。尊重用户指定的库；候选清单是参考，不是只能从中选择的限制。

给出适合当前需求的建议与理由。只有任务包括安装或接入时才实施，否则交付选型结论。
