# 物理交互设计

适用于用户要求的 Apple 风格交互或需要动量、阻尼与可中断过渡的组件。CageLedger 保持现有 Ant Design 外观、Token 和无障碍要求；不因引用本技能重做全站视觉。

- 拖动与手势从当前屏幕状态继续，反馈跟随输入；需要具体实现时查 [motion.md](references/motion.md) 对应小节。
- 需要材质、排版或空间层次建议时查 [design.md](references/design.md)。这些是设计参考，不是新增产品审批或警告的要求。
- 动画不得阻碍高频输入，保留键盘路径与 reduced-motion；验证被修改的真实交互，避免只凭参数判定效果。

用户要求实现时，完成实现和目标验收；原型、真人测试和隔日评审按实际任务需要选择。
