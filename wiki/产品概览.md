# 产品概览

CageLedger 面向实验动物中心的日常运营。系统以 IACUC 为主业务键，连接笼卡、笼位占用、数量统计表、饲养费结算和单据跟踪。

## 系统边界

| 领域       | 系统负责的工作                               | 主要结果                                 |
| ---------- | -------------------------------------------- | ---------------------------------------- |
| 笼卡管理   | 预约信息识别、批次维护、打印、接收与扫码查询 | 批次、笼卡、Animal Record ID、待进驻任务 |
| 笼位管理   | 房间、笼架、笼位、占用和待进驻维护           | 可追溯的笼位占用历史                     |
| 动物管理   | 房间巡检、异常登记、照片、处置与复查         | 巡检记录、异常项和处置时间线             |
| 饲养费管理 | 数量统计表、逐日计费、结算单、月度汇总       | 结算候选、结算版本、PDF、Excel           |
| 结算与报销 | 结算流程、报销单、经费明细和核销分摊         | 应收、已核销、待核销和审计记录           |

## 核心约束

- IACUC 连接项目负责人、实验负责人、项目来源、经费和有效期。
- Animal Record ID 是笼卡实例的持久身份，扫码、入驻和后续记录持续使用该标识。
- 数量统计表是当前启用的结算数据入口；动态笼位图保留为后续启用的数据入口。
- 结算按月、按费用产生项目负责人汇总；IACUC 和设施保留为明细维度。
- 报销经费负责人可与费用产生项目负责人不同，核销分摊完整记录双方关系。

## 技术组成

| 层级       | 当前实现                                                                 |
| ---------- | ------------------------------------------------------------------------ |
| Web 前端   | React 19、TypeScript、Vite、TanStack Query、TanStack Virtual、Ant Design |
| 移动端交互 | antd-mobile 与响应式工作区外壳                                           |
| HTTP 服务  | Python 3.13 标准库 HTTP 服务                                             |
| 业务与数据 | service/repository 分层、SQLite 与幂等迁移                               |
| 导出与打印 | 浏览器打印模板、服务端 PDF、Excel 月度汇总                               |
| 文档       | VitePress，生产路由为 `/docs/`                                           |
