# 产品概览

CageLedger 面向实验动物中心的接收、饲养、巡检与费用结算，以 IACUC 连接项目、笼卡、占用和账单，以 Animal Record ID 保留笼卡实例的持久身份。

## 当前业务能力

| 领域       | 系统负责的工作                                         | 主要结果                                 |
| ---------- | ------------------------------------------------------ | ---------------------------------------- |
| 笼卡管理   | 图文预约识别与核对、批次维护、打印、接收与扫码         | 批次、笼卡、Animal Record ID、待进驻任务 |
| 接收管理   | 独立接收登记、合格证留档和识别、预填表导出             | 实际登记与原件依据，不覆盖预约快照       |
| 检疫管理   | 批次、寄生虫／ELISA／PCR、复检、更正与完成确认         | 检测与报告版本、检疫记录                 |
| 笼位与动物 | 房间笼位占用、预留、巡检、异常处置与复查               | 占用历史、巡检和处置时间线               |
| 饲养费     | 月度数量统计、逐日计费、减免与自定义收费               | 按负责人汇总的饲养费账单                 |
| 技术服务费 | 按日期和实际服务数量核算                               | 独立技术服务明细与账单                   |
| 结算管理   | 共用结算列表、单据跟踪、交回登记、报销单补录与月度汇总 | 独立费用账单、登记金额、锁定归档与审计   |
| 系统支撑   | IACUC 和人员目录、权限、备份核查、帮助与反馈           | 可追溯的配置与运维记录                   |

## 核心边界

- IACUC 连接项目负责人、实验负责人、项目来源、经费与有效期；项目来源是 `funding` 的权威来源。
- 正式饲养费结算使用数量统计表。现役笼位管理维护占用；保留的动态笼位计费视图不是默认结算入口。
- 同月同负责人两类费用分别出单，IACUC 与设施保留为明细维度。
- 报销登记和补录在单据跟踪完成；登记后未归档，授权锁定后才显示已归档。
- 旧台账、应收和核销接口及数据保留兼容，当前工作台没有旧核销四页签，详见[当前版本与兼容边界](/development/current-baseline)。

## 技术组成

| 层级        | 当前实现                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------- |
| Web         | React 19、TypeScript、Vite、TanStack Query、TanStack Virtual、Ant Design；手机导航使用 antd-mobile |
| HTTP 与数据 | Python 3.13 标准库 HTTP 服务、领域 service/repository、SQLite WAL 与幂等迁移                       |
| 打印与导出  | 浏览器打印、Chromium PDF、LibreOffice 检疫报告、Excel                                              |
| 部署与文档  | ARM64 Docker 镜像、VitePress `/docs/`，运行依赖由锁定镜像管理                                      |
