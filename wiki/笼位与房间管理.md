# 笼位与房间管理

房间和笼架列表先显示结构与数量摘要；打开笼架编辑时再加载该架笼位。笼位图按所选房间读取工作数据，切换房间不会沿用上一房间的数据或选择。加载失败可在当前区域重试。

笼位图只加载当前在用、预约占用和未完成进驻任务；历史占用仍保存在系统中，原完整房间接口继续可用。选择和打开批量表单复用当前占用索引，笼架继续按行虚拟化。

本页覆盖饲养间、笼架、笼位结构，以及待进驻和占用维护。

## 房间布局

「设施」用于筛选饲养间。选定具体饲养间后显示笼架。100% 通过颜色和边框显示笼位使用情况，200% 按可用空间显示简略信息，300% 直接显示完整笼位卡片。前两档点击笼架会定位到该架，并放大到 300%。点击 300% 卡片可操作该笼位，点击比例或在图内按 Escape 可返回总览。指针在房间图内时，可用触控板捏合或 Ctrl／⌘ 加滚轮缩放房间图。

手动缩放和键盘移动焦点用于浏览。多选时，点击笼架或笼位后才能对该架使用「全选当前」。切换到其他笼架会清空原选择。

系统管理员及获授权的房间管理员可以点击「编辑布局」，拖动笼架、用方向按钮或键盘方向键逐格移动，也可旋转 90°。笼架会吸附到辅助网格，发生重叠时原位置保留。布局按房间共享，初次打开时系统会自动排放笼架。多人同时编辑时，保存较早的草稿会提示刷新后重新编辑。

占用中的笼位显示 IACUC、项目负责人和实验负责人的姓名、物种，以及已登记的品系和数量。猴笼同时显示性别和年龄。编辑笼位时可维护物种、品系、规格和性别。同一饲养间内相同 IACUC 使用同一底色，相邻笼位的不同 IACUC 优先采用色差明显的底色。已预留用琥珀色虚线边框，超期用红色边框。300% 卡片用琥珀色圆点提示结束日期待补。

## 业务对象

| 对象     | 说明                           |
| -------- | ------------------------------ |
| 饲养间   | 实际房间或区域                 |
| 笼架     | 饲养间中的架体                 |
| 笼位     | 架体上的具体位置               |
| 占用记录 | 某个笼位在一段时间内的占用历史 |

## 笼位状态

| 状态   | 含义                   |
| ------ | ---------------------- |
| 空     | 当前未占用             |
| 预约   | 已预约，尚未正式入驻   |
| 在用   | 已入驻并参与占用统计   |
| 已取材 | 项目结束，保留历史语义 |

“已取材”和“设为空”保留不同语义。

## 批量编辑

开始保存或设为空后，本轮表单及所见版本固定，按顺序处理并在结束时刷新房间一次。若部分失败，成功项保留，错误提示显示已处理数量；再次执行相同操作只继续未完成项，不重复提交已确认成功的笼位。遇到版本冲突需核对同事修改，可关闭编辑器重新读取后再操作。

## 待进驻任务

- 已接收笼卡会按每张笼卡生成待进驻任务
- 任务会在目标房间顶部展示
- 预留后会占用目标笼位为 `reserved`
- 正式入驻后会转为 `active`
- 系统管理员可在任务未完成前改签目标房间

## 房间维护原则

- 一个房间可以设置默认动物和默认收费项目
- 房间管理员只维护授权房间
- 笼架编号支持维护实际业务编号，不要求连续
- 删除笼架或笼位前先确认没有活跃占用
