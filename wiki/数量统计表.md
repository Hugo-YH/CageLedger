# 数量统计表

数量统计表服务于纸质台账录入、人工核对和动态笼位图数据未启用的场景。每张统计表属于一个月份、房间和 IACUC。

## 新建与基础信息

1. 打开“饲养费管理 → 录入数量统计表”。
2. 选择月份、房间和 IACUC。
3. 系统从 IACUC 索引回填项目名称、经费、项目负责人和实验负责人。
4. 确认收费项目和计费单位后录入统计表。

月份选择会带入当月第 1 天。保存的统计表不会把最后一条结余自动写入编辑页面的空白日期槽位。

输入 IACUC 后，编号下方会显示有效期气泡，悬停、聚焦或点击可查看完整起止日期。颜色与已保存列表一致：正常为蓝色，90 天内到期为黄色，已到期为红色。尚未开始、未取得完整有效期或查询失败也用红色提醒确认；补录月份早于开始日期或晚于结束日期时同样提醒。提示不阻止保存，减免仍按实际计费日期判定。

负责人支持填写多人，离开输入框后以顿号显示，人工补充保留；同一伦理号重复匹配和打开已有表时不会覆盖手动负责人。切换新伦理号仍重新匹配。已保存列表的项目负责人筛选按单个人匹配共同负责的表，多选不会重复列出同一张表。该筛选仅用于查找，结算仍按原完整负责人组合汇总，减免额度和历史账单快照保持原规则。

## 每日录入

- 每页左右两栏各 15 个日期槽位，按左侧再右侧的顺序对应月份日期。
- 录入新增、减少和结余总数时，可记录购入、转入、分笼、取材、死亡和转出语义。
- 转入和转出填写对方 IACUC，系统同步镜像记录和结算结果。
- 结余笼数由工作人员录入，作为按笼/天计费依据。
- 动物数量开关适用于需要维护动物只数的房间；按只/天计费的收费项目会要求补充动物数量。

## 计费扩展选项

扩展选项默认收起，按需展开。

| 选项           | 作用                                               |
| -------------- | -------------------------------------------------- |
| 优先减免       | 当前 IACUC 优先使用项目负责人减免额度              |
| 全额减免       | 有效期内每日实际饲养量全额减免，不占用普通额度     |
| 优先梯度       | 当前 IACUC 优先承接项目负责人超出阈值后的梯度收费  |
| 自定义收费区间 | 按日期、数量、单价和说明计费，独立于减免和梯度累计 |

“优先减免笼数/天”是当前 IACUC 每天固定优先取得的额度，不是最低减免数。取得指定额度后，
该 IACUC 当天不再参与剩余额度分配。只打开“优先减免”而不填写笼数时，当前 IACUC 会在普通 IACUC 之前参与剩余额度分配。

自定义收费区间支持同日多条记录。区间数量合计受当天动物数或笼数约束，超额保存时系统会提示具体日期和数量。

## 保存、预览和导出

- 已保存数量统计表列表支持排序、表头筛选、跨页全选与批量导出。
- 同一登录会话内切换到其他工作区再返回，会恢复已应用筛选、排序、页码、每页条数和滚动位置；批量勾选不随返回恢复，退出或刷新页面后列表偏好重置。
- 列表读取失败时可在错误提示中重试；翻页或刷新失败会保留上次成功结果并暂停选择、行操作和导出，成功更新后恢复。失败不会表示为零条记录。
- 预览、浏览器打印和服务端 PDF 使用同一份数量统计表模型。
- 预览与打印会补齐月份日期，并只在实际录入或连续结余需要展示时填入数值。
- 自定义收费区间作为附页明细保留在结算输出中。

计费规则详见 [饲养费核算](/guide/billing)。
