# 本地开发

本页说明 React、Python API 与 VitePress 文档站的本地开发方式。项目要求 Node.js `>=22.12.0 <23` 和 Python `3.13`。

## 安装依赖

```bash
npm ci
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

项目脚本默认使用 `.venv` 中的 Python 3.13，不回退到系统 Python。`scripts/python_runtime.mjs` 和 `scripts/check_python_runtime.mjs` 会解析并校验该运行时；已有其他 Python 3.13 环境时，可通过 `CAGELEDGER_PYTHON_BIN` 指定其可执行文件。

## 启动开发环境

```bash
npm run dev
```

该命令启动三个进程：

| 服务           | 默认地址                | 职责                             |
| -------------- | ----------------------- | -------------------------------- |
| Vite 应用      | `http://localhost:5173` | React 页面、热更新和 `/api` 代理 |
| Python API     | `http://127.0.0.1:5174` | SQLite、鉴权、业务 API           |
| VitePress 文档 | `http://127.0.0.1:5175` | `/docs/` 开发代理的文档站        |

常用覆盖参数：

```bash
CAGELEDGER_DEV_PORT=5183 CAGELEDGER_DEV_API_PORT=5184 CAGELEDGER_DOCS_PORT=5185 npm run dev
CAGELEDGER_EPHEMERAL_DB=1 npm run dev
```

第二条命令使用临时 SQLite，不写入 `data/`。

## 生产构建与本地生产运行

```bash
npm run build
node scripts/check_python_runtime.mjs
node scripts/run_python.mjs server.py
```

`npm run build` 构建 React 应用和 VitePress 文档站。Python 服务在 `5173` 提供门户 `/`、运营系统 `/app`、正式文档 `/docs/` 和 `/api`。

## 质量检查

日常修改按 [测试与质量](/development/testing-and-quality) 和 `docs/contracts/testing-strategy.md` 选择受影响文件与业务的检查，相关修改完成后统一验证。纯文字修改检查格式、lint、链接与 `git diff --check`；局部 UI 修改确认目标页面及相关交互。

`npm run check` 和 `npm run verify:full` 用于 Mac mini 发布前的完整验证，不作为每次修改、提交和推送的前置条件。API 冒烟与浏览器回归按实际影响选择；浏览器回归使用项目 Python 3.13 与临时数据库。
