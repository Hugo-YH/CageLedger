# 工作台导航

登录后按业务域进入工作区。桌面使用左侧菜单；手机通过高频入口和“更多”进入。下表对应当前默认导航，实际显示还受角色和系统功能配置控制。

| 一级模块       | 工作区                                                                             | 主要任务                                   |
| -------------- | ---------------------------------------------------------------------------------- | ------------------------------------------ |
| 主页           | 项目门户                                                                           | 返回产品与文档入口                         |
| 总览           | 运营摘要                                                                           | 查看设施、接收、待办、异常与饲养费统计     |
| 笼卡管理       | 预约消息识别、待接收批次、二维码扫描                                               | 预约核对、打印、接收确认和笼卡查询         |
| 接收管理       | 接收列表                                                                           | 独立登记、合格证留档与识别、接收登记表导出 |
| 检疫管理       | 检疫批次、寄生虫检测、ELISA检测、PCR检测、检疫报告                                 | 检测、复检、报告和整批完成确认             |
| 笼位管理       | 房间笼位图                                                                         | 维护占用、预留和待进驻任务                 |
| 动物管理       | 动物巡检、异常处置、巡检记录、巡检标准                                             | 巡检、处置与复查                           |
| 饲养费管理     | 录入数量统计表、已保存数量统计表                                                   | 维护正式饲养费结算来源                     |
| 技术服务费管理 | 录入技术服务明细、已保存技术服务明细                                               | 独立服务计费与明细维护                     |
| 结算管理       | 结算列表、单据跟踪、汇总导出                                                       | 两类费用独立出单、交回登记、补录与归档     |
| 帮助与反馈     | 反馈列表、提交和详情                                                               | 留档问题与查看处理进展                     |
| 系统设置       | 房间管理、实验人员信息、关于系统、系统功能、数据管理、数据核查、账号管理、操作日志 | 按角色维护基础数据、配置、权限与运行状态   |

“汇总导出”对系统管理员或具有结算锁定授权的账号开放；系统功能、数据管理、数据核查和账号管理仅管理员显示。其他页面仍按对应领域权限限制读写范围。

## 常用操作位置

- 页面工具栏承载当前对象的保存、新建、导出和扫描动作；表头提供排序和筛选，勾选后显示批量操作区。
- 预览、编辑和异常登记使用站内弹窗，关闭后返回原列表。
- 刷新、退出位于账户区域，手机通过“更多”使用。
- “系统设置 → 系统功能”控制八组业务入口显示；隐藏不改变后台权限或数据。

## 总览统计说明

统计按当前范围显示；没有记录、真实零值与读取失败分别提示。负责人金额和总饲养费不包含技术服务费；读取失败可以局部重试。

## 当前入口与历史代码

“核销中心”等旧四页签已移除。动态笼位管理仍在使用，但动态笼位计费不是当前正式结算入口。维护者请先阅读[当前版本与兼容边界](/development/current-baseline)，不要按孤立组件或旧文档寻找当前菜单。
