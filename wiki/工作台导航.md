# 工作台导航

登录后系统按业务域展示工作区。桌面端通过左侧菜单进入模块，移动端通过底部高频入口和“更多”菜单进入完整路径。

| 一级模块   | 工作区                                                     | 主要任务                                           |
| ---------- | ---------------------------------------------------------- | -------------------------------------------------- |
| 主页       | 运营摘要                                                   | 查看设施容量、待接收批次、待进驻任务、流程和异常项 |
| 笼卡管理   | 预约消息识别、待接收批次、二维码扫描                       | 接收、打印、确认和查询笼卡                         |
| 笼位管理   | 动态笼位图                                                 | 选择房间与笼架，维护占用、预留和待进驻任务         |
| 动物管理   | 动物巡检、异常处置、巡检记录、巡检标准                     | 创建巡检、登记异常、复查和查看标准                 |
| 饲养费管理 | 数量统计表、项目负责人结算、结算与报销台账、月度饲养费汇总 | 录入、结算、导出和核销                             |
| 系统设置   | 房间管理、数据管理、账号管理、操作日志、关于系统           | 配置基础数据、权限和系统信息                       |

## 常用操作位置

- 页面工具栏承载当前工作区的保存、新建、提交、导出和扫描等操作。
- 列表表头提供排序和筛选；勾选记录后显示批量操作区。
- 预览、编辑和异常登记使用统一弹窗，关闭后返回原列表位置。
- 刷新和退出位于导航栏账户区域；移动端收纳在“更多”菜单中。

## 权限可见性

系统管理员可访问全部配置和全局业务数据。房间管理员只看到授权范围内的设施数据，并可使用数量统计表、结算导出和流程发起等已授权入口。后端会对每次写入和读取再次校验权限。
