# 部署与运维

本区域面向部署人员、系统管理员和数据维护者。首次安装从部署开始，已有环境按配置、数据或故障选择入口；完成操作后，通过健康检查、角色权限及相关业务结果确认系统处于预期状态。

## 首次部署：从环境到可用系统

| 顺序 | 阅读入口                                                                    | 完成结果                                         |
| ---- | --------------------------------------------------------------------------- | ------------------------------------------------ |
| 1    | [部署与运行](/operations/deployment)                                        | 固定版本启动服务，确认端口、挂载和真实数据库路径 |
| 2    | [系统配置](/operations/configuration) · [环境变量](/operations/environment) | 明确组织、运行参数、外部服务及配置生效位置       |
| 3    | [账号与权限](/operations/accounts-and-permissions)                          | 管理员和房间管理员拥有符合职责的权限             |
| 4    | [HTTPS 与证书](/operations/https-and-certificate)                           | 按部署边界配置访问入口与证书信任                 |
| 5    | [备份与维护](/operations/backup-and-maintenance)                            | 保存同批数据、配置和版本，完成恢复演练           |

开发体验或界面演示应使用[本地开发](/development/local-development)中的隔离数据环境。生产镜像内已有运行依赖，日常部署不需要重新构建镜像。

## 日常维护：按任务进入

| 当前任务               | 阅读入口                                                    | 核对重点                               |
| ---------------------- | ----------------------------------------------------------- | -------------------------------------- |
| 更新伦理汇总与派生字段 | [数据管理与 IACUC 索引](/operations/data-and-iacuc)         | 导入结果、负责人、来源、有效期和回填   |
| 统一供应商名称         | [供应商简称映射](/operations/supplier-aliases)              | 匹配规则与接收记录显示                 |
| 管理账号和房间授权     | [账号与权限](/operations/accounts-and-permissions)          | 前端可见性与后端资源权限               |
| 升级或回退版本         | [部署与运行：升级与回滚](/operations/deployment#升级与回滚) | 固定 tag、备份批次、迁移兼容和业务验收 |
| 备份、恢复与日志保留   | [备份与维护](/operations/backup-and-maintenance)            | 数据库与附件同批、外置路径、恢复报告   |
| 服务或数据异常         | [故障排查](/operations/troubleshooting)                     | 首个失败请求、请求 ID、版本和脱敏日志  |

## 操作后的验收顺序

先确认 `/api/health` 返回预期版本，再验证登录、房间权限和本次操作涉及的数据。升级、迁移或恢复还要抽查数量统计表、结算、单据跟踪与附件下载；健康检查成功不代表整条业务链已经验收。

数据库默认路径取决于启动方式：源码为 `data/database/cageledger.sqlite`，镜像显式配置 `/app/data/cageledger.sqlite`，并允许环境变量覆盖。备份前始终按[实际路径规则](/operations/deployment#确认数据实际写在哪里)核对配置。

用户操作方法见[业务流程](/guide/business-flow)和[工作台导航](/guide/navigation)，版本变化见[更新日志](/releases/)。需要修改代码或准备制品时，进入[开发维护](/development/)。
