# 业务流程

当前业务围绕预约接收、检疫、饲养巡检和结算登记组织。各阶段有独立状态和审计；独立接收登记、检疫完成不自动改写预约或计费记录。

## 接收与入驻

1. 在“笼卡管理 → 预约消息识别”输入文字或原图，核对编号、IACUC、品系、数量、房间和日期；发现同一预约时按统一核对弹窗处理。
2. 保存待接收批次、打印笼卡，到货后在待接收批次确认接收。
3. “接收管理 → 接收列表”维护独立实际登记、合格证原件和识别结果；人工核对后确认，可导出接收登记表。
4. 饲养用途的已接收笼卡生成待进驻任务，在“笼位管理”先预留目标笼位，再正式入驻；直接取材用途不生成普通待进驻任务。

详见[笼卡管理](/guide/cage-cards)和[笼位与房间管理](/guide/rooms-and-cages)。

## 检疫与巡检

1. 已全部接收且适用检疫的来源出现在待检疫列表，勾选建立批次。
2. 分别录入寄生虫、ELISA、PCR 检测，下载草稿核对，出具报告；异常按原流程复检和处理。
3. 完成所需检测、结论和异常处理后人工确认整批检疫完成；更正或复检会重新进入检疫中。
4. 日常在动物管理按房间巡检，记录异常、照片、处置与复查。

详见[检疫管理](/guide/quarantine)和[动物巡检](/guide/animal-inspection)。

## 费用与结算

1. 饲养费在数量统计表按月、房间和 IACUC 录入数量、减免及收费设置。
2. 技术服务费在独立明细中按服务日期填写实际计费数量。
3. 共用结算列表按月和负责人分别汇总两类费用，预览、导出并发起流程；两类费用不合成一张账单。
4. 系统管理员或具有结算锁定授权的账号按月执行汇总导出。

详见[数量统计表](/guide/quantity-sheets)、[饲养费核算](/guide/billing)与[技术服务费管理](/guide/technical-services)。

## 单据跟踪

1. 已发起流程进入单据跟踪，线下完成签字后在系统执行交回登记。
2. 结算单已交回后可保存登记；报销单按经费本编号、单号和金额逐行登记，实收金额自动汇总。
3. 登记后处于已登记、未归档；未交的报销单可按授权补录，流程阶段不改变。
4. 授权账号可锁定已发起或已登记流程，此时显示已归档；解锁恢复锁定前阶段和未归档状态。
5. 未归档单据按权限和原因撤回：已登记 → 已发起 → 已生成；已生成可撤销删除流程，资金关联保护仍保留。

详见[结算与报销](/guide/settlement-and-reimbursement)。当前界面不提供旧应收、报销单、核销中心、历史台账四页签。
