# 业务流程

系统围绕接收、饲养、结算和核销组织工作。各阶段的业务记录保留独立状态和审计信息。

## 接收与入驻

1. 在“笼卡管理”粘贴预约接收文本并执行识别。
2. 校验批次号、IACUC、品系、数量、目标房间和接收日期后保存待接收批次。
3. 打印笼卡并在到货后确认接收。
4. 系统为已接收笼卡生成待进驻任务。
5. 在“笼位管理”预留或正式入驻目标笼位。

详见 [笼卡管理](/guide/cage-cards) 和 [笼位与房间管理](/guide/rooms-and-cages)。

## 饲养与巡检

1. 笼位图维护当前占用和结束日期。
2. 动物管理按饲养间创建巡检，选择基础、进阶或异常动物评估模块。
3. 异常条目记录笼架、笼号、动物标识、现场说明和照片。
4. 处置项按待处理、处理中、待复查和已关闭推进。

详见 [动物巡检](/guide/animal-inspection)。

## 数量统计与结算

1. 数量统计表按月、房间和 IACUC 录入每日变化、结余总数和结余笼数。
2. 系统以数量统计表作为当前结算数据来源。
3. 系统按项目负责人、IACUC 有效期、减免、梯度和自定义收费规则计算。
4. 结算管理列表生成同月合表预览、PDF，并发起结算流程（已生成 → 已发起）。
5. 系统管理员按月导出饲养费汇总 Excel。

详见 [数量统计表](/guide/quantity-sheets) 与 [饲养费核算](/guide/billing)。

## 单据跟踪与补录

1. 结算流程发起后进入单据跟踪（已发起 → 已归档）。
2. 工作人员在系统外完成签字后，在单据跟踪执行“登记”，填写结算单/报销单交回情况并上传扫描附件，登记后自动归档。
3. 实收金额按报销单金额自动汇总；无报销单则为 0。
4. 已归档且报销单未交的流程，后期可在单据跟踪“补录报销单”，流程保持已归档。
5. 每步可撤回上一状态（已发起→已生成、已归档→已发起）或撤销整个流程（已生成→未发起），系统保留完整事件记录。

详见 [结算与报销](/guide/settlement-and-reimbursement)。
