# 帮助与反馈

所有登录同事都能查看反馈及处理进展，公开主页没有此入口。普通同事无需 Gitea 账号。

## 提交与补充

1. 进入“帮助与反馈”，填写标题、类型、所属模块和描述。
2. 核对展示的版本、Build、工作页面和浏览器信息。系统不会自动采集网址参数、Cookie、业务表格或完整日志。
3. 手工选择截图，每次最多五张 PNG、JPEG、WebP，单张不超过 10MiB。
4. 提交后先取得系统反馈记录，后台再同步 Gitea 工单。附件失败时本地记录仍然存在，可以重试附件。

原始内容保留，修正通过追加补充完成。所有同事可追加公开说明，或点击“我也遇到了”；再次点击可取消，同一人仅计一次。列表使用表头漏斗筛选：点击对应列的漏斗，搜索候选项并勾选，点击“应用”后生效。列内支持多选，不同列同时满足；候选项和数量覆盖全部分页，保留其他列的筛选范围。提出人列可选择自己；点击工具栏“清空筛选”恢复全部反馈。点击列标题可切换排序。

## 处理进展

开发在 Gitea 维护状态、负责人和里程碑。系统不提供另一套状态编辑入口；修复版本取里程碑名称，未设置时留空。仅同步由系统关联的工单；历史手工工单由管理员选择导入，不自动公开仓库全部工单。

| 工单状态与流程标签           | 系统显示   |
| ---------------------------- | ---------- |
| 开启，无标签或 `反馈/待处理` | 待处理     |
| 开启，`反馈/处理中`          | 处理中     |
| 开启，`反馈/待验证`          | 待验证     |
| 关闭，`反馈/已解决`          | 已解决     |
| 关闭，其他情况               | 已关闭     |
| 开启，多个流程标签           | 状态待确认 |

确认 Gitea 工单已删除后，系统同步移除对应反馈：列表不再展示，原详情、补充和截图链接均不可访问，待同步任务停止。后台采用逻辑删除，保留删除标记和审计记录，旧请求重试不会重新创建工单；不提供已删除反馈的只读页面。若删除时详情已打开，显示“反馈已删除”，可返回已刷新的列表。仓库或权限不可访问、临时网络故障不会被当作删除。

其他分类标签不参与状态计算。重开工单不沿用“已解决”。关闭原因由开发在评论说明。

已关联工单每五分钟更新；进入详情时若缓存超过一分钟，后台请求检查，同时立即显示缓存内容及最后同步时间。开发评论编辑、删除也会同步。去除开头空白后以 `【内部】` 开头的评论和附件不在系统展示，管理员也看不到；此前已读内容无法撤回。

正文和回复支持 Markdown 标题、列表、引用、粗体、斜体、删除线、表格、链接及代码块；表格和长代码可在局部滚动，普通换行保留。原始内容仍完整留档，不执行 HTML，不自动加载外部图片；正文图片位置显示附件提示，截图请在附件区查看或上传。

## 同步异常

业务状态和同步状态分别显示。没有 Token、权限不足或断网时，反馈继续留档，后台网络错误退避重试。鉴权错误暂停请求，由管理员处理凭据后重试；Token 配置见 [[系统配置]]。

管理员可查看同步错误、复制核对标识、重试以及打开开发工单。请求超时且结果不确定时，系统先通过稳定标识核对工单、补充或附件。没有找到时暂停该任务，管理员应先核实远端，不会通过反复点击重试盲目创建重复工单。改变仓库地址不会自动迁移历史工单。

第一版没有 Webhook、邮件或站外消息通知。开发测试使用隔离数据库和模拟 Gitea，真实仓库联调需单独授权。备份须同时包含 SQLite 和 `data/files/feedback/`，见 [[备份与维护]]。

## 导入历史工单

管理员进入“帮助与反馈 → 导入历史工单”，预览同一仓库的全部、未关闭或已关闭工单，勾选后导入。翻页保留选择，切换工单范围时清空并提示；每次最多十条，超过一页时可分批操作。普通同事没有导入权限，但可以查看、补充导入后的反馈。

导入关联原工单，不新建另一张工单。保留正文、原创建日期、公开评论和截图，后续处理状态、负责人、修复版本及评论继续同步。正文里的“提出人”优先，旧标题中的 `@姓名` 也会识别；两者均未注明时显示 Gitea 登记账号并注明来源。导入管理员另行记录，不冒充原提出人。类型优先识别“故障”，再识别“使用疑问”，其余按“功能建议”；模块优先取原文的“涉及模块”或“模块”，其次取标题方括号，缺失显示“未分类”。导入只保存原文快照，不从关闭状态或回复猜测修复版本。

已关联、已删除、合并请求、内部正文以及系统自动创建的工单不会重复导入。请求中断可点“重试导入”，系统核对同一请求；逐项结果明确列出成功、跳过和失败，失败项保留选择，可处理原因后再次导入。没有共享 Token 或无法读取仓库／工单时，不会导入对应反馈；导入操作不会修改远端工单。超过标题／正文安全长度的记录会提示失败，保留 Gitea 原文。
