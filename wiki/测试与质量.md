# 测试与质量

质量门禁覆盖前端、后端、文档、接口、浏览器回归、性能和发布制品。日常开发使用最小匹配的检查集，发布执行完整验证。

## 常用命令

| 命令                  | 覆盖范围                                                                          |
| --------------------- | --------------------------------------------------------------------------------- |
| `npm run check`       | 格式、lint、类型、Vitest、Python unittest、架构门禁、UI 契约和 VitePress 文档构建 |
| `npm run build`       | React 应用与 VitePress 生产构建                                                   |
| `npm run smoke:api`   | 管理员与房间管理员 API 冒烟                                                       |
| `npm run test:e2e`    | Playwright 浏览器回归与 Axe 检查                                                  |
| `npm run benchmark`   | 列表、结算和大型笼位图性能基准                                                    |
| `npm run verify:full` | 基础检查、生产构建和完整 Playwright                                               |

## 检查选择

| 改动                       | 最低验证                             |
| -------------------------- | ------------------------------------ |
| 文档与低风险样式           | `npm run check`、`git diff --check`  |
| React 交互                 | 上述检查和目标页面浏览器验证         |
| API、权限、缓存与迁移      | `npm run check`、`npm run smoke:api` |
| 结算、数量统计、流程与报销 | 对应 Vitest/Python 测试和目标 E2E    |
| 打印、PDF、Excel           | 模板测试、预览、多页和下载文件检查   |

## 浏览器回归运行时

`npm run test:e2e` 通过 `scripts/check_python_runtime.mjs` 固定使用项目 `.venv` 的 Python 3.13。测试使用独立端口和临时 SQLite，避免写入日常开发数据。

完整策略见 `docs/contracts/testing-strategy.md` 和 `docs/contracts/code-quality.md`。
