# 使用指南

本指南面向日常工作人员与房间管理员。已经取得账号后，从[快速开始](/guide/getting-started)完成第一次操作；系统管理员的安装和配置任务位于[部署运维](/operations/)。

## 先了解三个位置

- **工作台导航**：按当前账号权限与系统功能开关展示菜单，详见[工作台导航](/guide/navigation)。
- **业务记录**：预约、实际接收、检疫、占用和巡检分别保存，前一阶段完成不代表后一阶段自动完成。
- **费用单据**：饲养费以数量统计表为正式来源，技术服务费以服务明细为来源；两类费用分别出单，共用单据跟踪。

## 按工作顺序阅读

| 工作阶段   | 操作指南                                                                      | 完成后核对                        |
| ---------- | ----------------------------------------------------------------------------- | --------------------------------- |
| 预约与到货 | [笼卡与接收](/guide/cage-cards)                                               | 批次、打印数量、实际接收与用途    |
| 检疫与报告 | [检疫管理](/guide/quarantine)                                                 | 所需报告、异常处理与整批完成状态  |
| 预留与入驻 | [笼位与房间](/guide/rooms-and-cages)                                          | 目标房间、笼位与 Animal Record ID |
| 日常巡检   | [动物巡检](/guide/animal-inspection)                                          | 异常、处置和复查记录              |
| 月度费用   | [数量统计表](/guide/quantity-sheets)、[技术服务费](/guide/technical-services) | 来源数据、月份、IACUC 与负责人    |
| 出单与登记 | [结算与报销](/guide/settlement-and-reimbursement)                             | 冻结账单、交回登记与归档状态      |

## 需要查询某个操作

[操作手册索引](/guide/user-manual)按常用任务定位页面；[常见问题](/guide/faq)解释易混淆的结果。功能入口不见时，先核对[账号与权限](/operations/accounts-and-permissions)和系统功能开关；操作报错时记录步骤、发生时间与提示，再通过[帮助与反馈](/guide/feedback)留档。
