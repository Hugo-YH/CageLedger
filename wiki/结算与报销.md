# 结算与报销

结算管理负责“生成 → 发起”阶段，单据跟踪负责“已发起之后的交回、归档与补录”。结算单按项目负责人汇总，保留 IACUC 与设施明细。

## 结算管理

1. 打开“饲养费管理 → 结算管理”。
2. 使用月份、项目负责人和 IACUC 等表头筛选定位候选记录。
3. 选择一个或多个候选项，预览结算单、打印、下载 PDF，或批量发起结算流程。
4. 系统按同月、同项目负责人自动合并相关 IACUC，并保留设施和 IACUC 明细。

结算状态：

| 状态   | 说明                                                           |
| ------ | -------------------------------------------------------------- |
| 未发起 | 尚未生成结算流程                                               |
| 已生成 | 结算流程已生成但未发起，可发起，也可撤销（删除流程回到未发起） |
| 已发起 | 结算流程已发起，进入单据跟踪处理                               |

列表由后端结算候选快照支持。数量统计表、IACUC 或计费规则变动后，受影响月份和项目负责人的快照会刷新。

## 单据跟踪

单据跟踪展示已发起之后的结算流程（已发起、已归档），不再展示“已生成”。

状态流转：

```text
已生成 -> 已发起 -> 已归档 -> 已锁定
```

- 已发起流程可“登记”（交回登记），填写结算单/报销单交回情况后归档；也可“撤回”退回已生成（回到结算管理重新发起）。
- 已归档流程展示“结算单 ✅ 已交回 / 报销单 未交回”两个子状态；可查看归档（流程记录时间轴）、补录报销单、撤回退回已发起，或锁定进入终态。
- 已锁定流程展示“已锁定”标签；所有人可查看归档，授权账号可补录报销单或解锁，解锁前不允许撤回/撤销。
- 锁定、解锁和已锁定流程的补录需要“结算锁定授权”，在账号管理中按账号授予；单据跟踪支持勾选多条已归档流程批量锁定。

### 交回登记

- 结算单开关打开后上传结算单扫描件（非必填）。
- 报销单开关打开后按“报销单号 + 金额”逐行登记，可多条；实收金额自动按报销单金额汇总（无报销单则为 0）。
- 结算金额为 0 的流程不显示报销单开关。
- 登记并归档后流程进入已归档。

### 补录报销单

标记为已交回结算单但报销单未交的流程，后期可补录报销单（报销单号、金额、扫描件），实收金额按全部报销单重新汇总，流程保持已归档。

### 流程记录

查看归档弹窗以时间轴展示流程记录：数量统计表登记、饲养费核算汇总表生成、发起结算流程、结算单/报销单交回；中间的撤回、退回、补录等历史记录默认折叠为“历史记录”。

## 术语约定

- 撤回：把流程退回上一状态（已发起→已生成、已归档→已发起），按钮白底红字。
- 撤销：删除整个结算流程（已生成→未发起），按钮红底白字。

月度 Excel 产出详见 [饲养费核算](/guide/billing)。
