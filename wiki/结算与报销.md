# 结算与报销

当前入口是“结算管理 → 结算列表／单据跟踪／汇总导出”。饲养费与技术服务费按月、按项目负责人分别出单，IACUC 与设施保留为明细维度。旧结算应收、报销单、核销中心和历史台账四页签已退出工作台，兼容范围见[当前版本与兼容边界](/development/current-baseline)。

## 结算列表

1. 打开“结算管理 → 结算列表”，按月份、项目负责人、IACUC 和费用类型等列头筛选定位记录。
2. 预览、打印、下载 PDF／Excel，或选择多个候选项批量发起结算。
3. 同月同负责人的相关 IACUC 自动合表；饲养费与技术服务费始终为两种独立账单，不因筛选单个伦理而缩减账单内的范围。
4. 准备通知邮件时核对最新金额；确认后发起流程，邮件内容供复制，不自动发送邮件。

| 阶段   | 说明                                                 |
| ------ | ---------------------------------------------------- |
| 未发起 | 尚无对应结算流程                                     |
| 已生成 | 已有结算流程但未发起；可发起，也可按权限撤销删除流程 |
| 已发起 | 已发起流程，在单据跟踪进行交回登记或其他处理         |

列表由后端候选快照支持；来源或配置变化后刷新受影响范围。已发起的有效账单使用冻结版本，不因重新读取而采用当前单价或来源。

## 单据跟踪

单据跟踪展示已发起及之后的流程；已生成流程仍在结算列表处理。**流程阶段与归档状态分别显示：保存交回登记进入“已登记”，仍是“未归档”；锁定后才显示“已归档”。**

```text
已生成 → 已发起 → 已登记
           ↓         ↓
         锁定（已归档）
解锁 → 未归档，恢复锁定前的已发起或已登记阶段
```

- 系统管理员和房间管理员均可为已发起且未归档的流程登记，不要求本人发起。
- 已登记流程可查看流程记录、按授权补录报销单，或填写原因撤回到已发起。
- 已发起、已登记流程均可由系统管理员或有结算锁定授权的账号锁定；批量锁定按实际选中且可处理的流程执行。
- 已归档流程可查看；解锁与归档后补录需要系统管理员或结算锁定授权。解锁保留已有登记和报销单信息。
- 系统管理员、实际经手人和有结算锁定授权的账号可按状态撤回未归档单据。经手资格按账号 ID、来源统计表审计与流程事件识别，历史版本经手记录保留；同名和仅查看不会取得资格。

### 交回登记

打开已发起流程的“登记”，确认结算单已交回；扫描件可按需上传。选择报销单已交回时，逐行填写“经费本编号 + 报销单号 + 金额”，可登记多张。经费本候选按关联 IACUC 读取最新申请资料，手工输入非候选项时按提示核对支撑经费。

实收金额按已登记报销单金额自动汇总；没有报销单时为 0。结算金额为 0 的流程无需交回报销单。点击“保存登记”后进入已登记阶段，不自动锁定归档。

### 补录报销单

在已登记流程的查看弹窗中，按现有授权补录未交的报销单、金额、经费本编号及附件。已归档流程只有系统管理员或具有结算锁定授权的账号可补录。补录不改变当前流程阶段或归档状态，实收金额重新汇总。

### 撤回、撤销与流程记录

- 撤回：填写原因后退回上一阶段，已登记退回已发起，已发起退回已生成。已归档流程须先解锁。
- 撤销：删除已生成的流程，回到未发起；已有已确认核销等资金关联时仍执行原保护，不能绕过。
- 查看：按时间线保留数量表登记、账单生成／发起、交回、补录及锁定记录；历史重复过程默认折叠。

为兼容旧库，内部 `statement_archived` 继续表示已登记且未归档，`statement_locked` 表示锁定且已归档。旧“签字退回／已交财务”等历史状态继续可读，不作为当前新的操作步骤。

## 账单快照与历史资金记录

发起时保存项目、来源、数量、收费标准与金额的有效版本；预览、打印、PDF 和 Excel 读取同一版本。需要采用修改后的数据时先按权限撤回再重新生成，或执行明确的修订操作。缺失或损坏的历史版本不使用实时数据替代。

旧应收、报销单及核销接口和历史审计仍保留。撤销流程时，无核销关联的应收可以清理；有历史关联的记录按原规则留存，有已确认核销的流程继续受资金保护。当前工作台不提供独立核销操作页，不以旧接口的存在推断当前菜单。

月度 Excel 见[饲养费核算](/guide/billing)与[技术服务费管理](/guide/technical-services)。
