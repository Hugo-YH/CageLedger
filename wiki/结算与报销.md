# 结算与报销

项目负责人结算与报销台账是两条关联链路。结算记录费用产生项目负责人，报销单记录经费负责人，核销分摊保存两者之间的金额关系。

## 项目负责人结算

1. 打开“饲养费管理 → 按项目负责人结算”。
2. 使用月份、项目负责人和 IACUC 等表头筛选定位候选记录。
3. 选择一个或多个候选项，预览结算单、打印、下载 PDF，或批量发起结算流程。
4. 系统按同月、同项目负责人自动合并相关 IACUC，并保留设施和 IACUC 明细。

列表由后端结算候选快照支持。数量统计表、IACUC 或计费规则变动后，受影响月份和项目负责人的快照会刷新。

## 流程中心

结算流程记录结算单从生成到提交财务的状态：

```text
statement_generated -> statement_sent -> statement_signed_returned -> submitted_to_finance
```

流程详情保留版本、事件和逐日结算明细。生成新版本前已有确认核销时，系统会保留历史版本并生成差额调整应收。

## 结算与报销台账

台账分为四个页签：

| 页签     | 内容                                                            |
| -------- | --------------------------------------------------------------- |
| 结算应收 | 结算月份、费用产生项目负责人、IACUC、应缴、已核销、待核销和状态 |
| 报销单   | 报销单号、经费负责人、经费明细、附件、总额与状态                |
| 核销中心 | 经费明细与结算应收的多对多分摊、草稿、确认与撤销                |
| 历史台账 | 兼容保留的历史记录和管理员迁入入口                              |

一张报销单包含一条或多条经费明细。同一张报销单的经费明细使用同一位经费负责人。经费明细可分摊到多张结算应收，一张结算应收也可由多条经费明细共同核销。

## 附件与核销约束

- 报销单附件支持 PDF、JPEG、PNG；单文件最大 30 MiB，每张报销单最多 10 个附件。
- 经费明细的已确认分摊金额不得超过报销金额。
- 结算应收的已确认分摊金额不得超过应缴金额。
- 系统管理员确认或撤销核销，操作日志记录金额、操作人、时间和撤销原因。

月度 Excel 产出详见 [饲养费核算](/guide/billing)。
