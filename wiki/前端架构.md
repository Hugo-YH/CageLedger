# 前端架构

前端采用 React 19、TypeScript、Vite、TanStack Query、TanStack Virtual、Ant Design 和 antd-mobile。业务页按领域拆分，页面通过 typed API hooks 获取服务端状态。

## 目录与职责

| 路径                       | 职责                                              |
| -------------------------- | ------------------------------------------------- |
| `src/main.tsx`             | 前端启动和全局样式入口                            |
| `src/react/App.tsx`        | 门户、登录、工作区和公开扫码路由分流              |
| `src/react/features/`      | 笼卡、笼位、动物、饲养费、流程和设置工作区        |
| `src/react/components/ui/` | Ant Design 适配层和公共交互组件                   |
| `src/react/api/`           | 请求 client、contracts、Query hooks 和 query keys |
| `src/react/state/`         | 当前视图、导航和主题等 UI 偏好                    |
| `src/domain/`              | 日期、IACUC、数量和计费等纯计算                   |
| `src/react/print/`         | 打印与预览共享模板                                |
| `src/styles/`              | Token、基础、壳层、组件、业务、打印和响应式样式   |

## 数据流

```mermaid
flowchart LR
  View[Feature View] --> Hook[Typed Query Hook]
  Hook --> Client[API Client]
  Client --> Api[/api]
  Api --> Hook
  Hook --> View
```

- 服务端数据由 TanStack Query 缓存。默认 `staleTime` 为 15 秒，`gcTime` 为 5 分钟。
- 写入成功后按受影响范围失效查询键，页面不保存业务副本。
- 高频表格输入使用局部 state，避免输入期间整页刷新和失焦。
- 业务页通过 `React.lazy` 分包加载，扫码依赖按需导入。

## UI 约定

桌面和平板工作区使用 Ant Design，移动端高频导航使用 antd-mobile。页面使用项目 UI 适配层提供的操作栏、表格、表单、状态和弹窗，业务专用样式只服务笼位图、数量网格、巡检评分和打印模板。

详见 [UI 组件标准](/development/ui-component-standard) 和 `docs/contracts/frontend-state.md`。
