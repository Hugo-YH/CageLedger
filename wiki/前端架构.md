# 前端架构

本页面向修改 React 页面、查询缓存和公共交互的开发者。从实际工作区入口追踪 View、typed hook 和 HTTP 请求，可确定修改位置、数据归属及需要验证的消费者。技术栈为 React 19、TypeScript、Vite、TanStack Query、TanStack Virtual、Ant Design 和 antd-mobile。

## 从页面入口定位职责

| 层次           | 主要路径                                           | 修改时关注                                        |
| -------------- | -------------------------------------------------- | ------------------------------------------------- |
| 启动与会话     | `src/main.tsx`、`src/react/App.tsx`                | QueryClient、Provider、登录、工作区及公开扫码分流 |
| 工作区与领域   | `src/react/features/shell/`、`src/react/features/` | 导航、角色可见性、功能开关与懒加载 View           |
| 公共交互       | `src/react/components/ui/`                         | Ant Design 适配、表格、表单、弹窗与反馈           |
| 服务端状态     | `src/react/api/`、`src/contracts/`                 | client、响应类型、查询键、查询与写入 hooks        |
| 局部状态与计算 | `src/react/state/`、`src/domain/`                  | UI 偏好、局部草稿及可独立验证的纯计算             |
| 输出与外观     | `src/react/print/`、`src/theme/`、`src/styles/`    | 共享打印模板、主题源与样式归属                    |

## 请求、缓存与写入回流

<DocFigure src="/diagrams/request-lifecycle.svg" kind="diagram" alt="页面经 typed hook 和 API 进入领域服务，并在写入后更新查询与操作反馈" caption="沿页面到 API 定位读取链路，再沿写入回流核对查询刷新和操作反馈。" />

后端的分层职责见[后端架构](/development/backend-architecture)。

服务端业务对象由 TanStack Query 管理，页面通过 typed hooks 读取，避免在 reducer 中维护另一份业务副本。项目 `queryClient.ts` 将查询默认新鲜时间设为 15 秒、未使用缓存保留时间设为 5 分钟，关闭窗口聚焦自动刷新；可恢复的查询错误最多重试一次，mutation 默认不重试。业务 hook 可按契约覆盖默认配置。

写入完成后，按受影响对象更新或失效 `queryKeys.ts` 中的查询键。高频表格和表单输入留在局部草稿，成功保存再回流业务缓存，避免输入时整页刷新或失焦。详细规则统一维护在仓库 `docs/contracts/frontend-state.md` 和 `api-contracts.md`；TanStack 官方默认行为可作为理解缓存配置的补充。<sup>[1](#参考资料)</sup>

## 现役入口与历史实现

是否仍在使用，需同时核对 HTML 入口、实际 View、桌面／手机导航、角色和功能开关。[当前版本与兼容边界](/development/current-baseline)提供已核实的映射，`npm run check:frontend-lifecycle` 则核对生产运行时依赖、纯类型依赖和历史保留清单。

当前 `WorkflowCenterView` 只挂载 `BillingWorkflowPanel`。旧应收、报销单、核销中心和历史台账页签，以及旧预约文字补充弹窗保留实现和独立测试，但没有当前生产入口。共用工具、扫码 Worker 和后端兼容 API 需分别判断；静态检查通过也不能替代角色权限和真实用户流程验证。

## UI、主题与输出

桌面和平板工作区使用 Ant Design，移动端高频导航使用 antd-mobile。新增交互优先复用项目适配层；业务专用样式用于笼位图、数量网格、巡检评分和打印模板等领域表达。

主题唯一源为 `src/theme/visual-system.mjs`，派生 Token 供应用与文档使用。样式按 `src/styles/style-ownership.json` 登记归属，`src/styles.css` 保持导入入口。按钮、表单、反馈和弹窗规范见 [UI 组件标准](/development/ui-component-standard)；视觉语言、颜色和样式细则分别见仓库 `docs/contracts/antd-design-language.md`、`ui-color-system.md`、`style-ownership.md`。

预览与打印复用 `src/react/print/` 模板。涉及结算汇总时还要核对 Python PDF 的等价输出，验证入口见[测试与质量](/development/testing-and-quality)。
