# 环境变量

环境变量用于配置服务端口、数据目录、初始管理员、系统展示信息、更新检查和附件目录。配置完成后重启服务生效。

## 服务与数据

| 变量                                       | 默认值                                            | 用途                                   |
| ------------------------------------------ | ------------------------------------------------- | -------------------------------------- |
| `CAGELEDGER_HOST`                          | `0.0.0.0`                                         | HTTP 服务监听地址                      |
| `CAGELEDGER_PORT`                          | `5173`                                            | HTTP 服务端口                          |
| `CAGELEDGER_DATA_ROOT`                     | `data/`                                           | 运行时存储根目录                       |
| `CAGELEDGER_DB`                            | `data/database/cageledger.sqlite`                 | SQLite 数据库路径（覆盖根目录派生值）  |
| `CAGELEDGER_IACUC_INDEX`                   | `data/indexes/iacuc/index.json`                   | IACUC 索引文件路径（覆盖根目录派生值） |
| `CAGELEDGER_PDF_CACHE`                     | `data/cache/pdf/`                                 | PDF 缓存目录（覆盖根目录派生值）       |
| `CAGELEDGER_ANIMAL_INSPECTION_IMAGES`      | `data/files/animal-inspections/reference-images/` | 巡检参考图目录                         |
| `CAGELEDGER_ANIMAL_INSPECTION_ATTACHMENTS` | `data/files/animal-inspections/attachments/`      | 巡检附件目录                           |
| `CAGELEDGER_REIMBURSEMENT_ATTACHMENTS`     | `data/files/reimbursements/attachments/`          | 报销单附件目录                         |

`CAGELEDGER_DATA_ROOT` 统一管理默认运行目录。各专项路径变量保留给独立挂载和历史部署使用，显式设置后优先级最高。

## 初始账号与系统信息

| 变量                        | 默认值               | 用途                 |
| --------------------------- | -------------------- | -------------------- |
| `CAGELEDGER_ADMIN_USERNAME` | `admin`              | 首次启动的管理员账号 |
| `CAGELEDGER_ADMIN_PASSWORD` | `admin123`           | 首次启动的管理员密码 |
| `CAGELEDGER_ORGANIZATION`   | 中山大学中山眼科中心 | 系统归属单位         |
| `CAGELEDGER_DEPARTMENT`     | 实验动物中心         | 系统归属部门         |
| `CAGELEDGER_DEVELOPER`      | `Hugo`               | 开发者展示信息       |
| `CAGELEDGER_CONTACT_EMAIL`  | `info@cellnucle.us`  | 联系邮箱             |
| `CAGELEDGER_LICENSE`        | `Apache-2.0`         | 许可证展示信息       |

## 版本与更新检查

| 变量                              | 默认值         | 用途                             |
| --------------------------------- | -------------- | -------------------------------- |
| `CAGELEDGER_APP_VERSION`          | 构建注入       | 运行版本展示                     |
| `CAGELEDGER_REVISION`             | 构建注入       | 构建 revision 展示               |
| `CAGELEDGER_REPOSITORY_URL`       | Gitea 仓库地址 | Release 和源码入口               |
| `CAGELEDGER_BRANCH`               | `main`         | 当前分支展示                     |
| `CAGELEDGER_UPDATE_CHECK_ENABLED` | `false`        | 启用 Gitea 更新检查              |
| `CAGELEDGER_GITEA_TOKEN`          | 空             | 私有仓库更新检查使用的只读 token |

生产环境将 token 写入部署平台的密钥配置。`.env` 文件和 token 不进入版本库。
