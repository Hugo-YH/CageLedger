# 环境变量

环境变量用于配置服务端口、数据目录、初始管理员、系统展示信息、更新检查和附件目录。配置完成后重启服务生效。

## 服务与数据

| 变量                                       | 默认值                                            | 用途                                                           |
| ------------------------------------------ | ------------------------------------------------- | -------------------------------------------------------------- |
| `CAGELEDGER_ENV`                           | `development`（容器为`production`）               | 生产首次创建管理员要求显式设置至少12位随机密码，已有账号不重置 |
| `CAGELEDGER_HTTP_MAX_WORKERS`              | `32`                                              | 并发连接上限，超限503并关闭连接                                |
| `CAGELEDGER_PDF_MAX_PENDING`               | `32`                                              | 导出排队及执行任务总上限；预热优先让出容量                     |
| `CAGELEDGER_PDF_RENDER_MAX_PENDING`        | `32`                                              | 常驻PDF渲染器排队上限，保留独立停机槽位                        |
| `CAGELEDGER_HOST`                          | `0.0.0.0`                                         | HTTP 服务监听地址                                              |
| `CAGELEDGER_PORT`                          | `5173`                                            | HTTP 服务端口                                                  |
| `CAGELEDGER_DATA_ROOT`                     | `data/`                                           | 运行时存储根目录                                               |
| `CAGELEDGER_DB`                            | `data/database/cageledger.sqlite`                 | SQLite 数据库路径（覆盖根目录派生值）                          |
| `CAGELEDGER_IACUC_INDEX`                   | `data/indexes/iacuc/index.json`                   | IACUC 索引文件路径（覆盖根目录派生值）                         |
| `CAGELEDGER_PDF_CACHE`                     | `data/cache/pdf/`                                 | PDF 缓存目录（覆盖根目录派生值）                               |
| `CAGELEDGER_PDF_CACHE_MAX_BYTES`           | `536870912`                                       | PDF 缓存容量上限（默认 512 MiB）                               |
| `CAGELEDGER_PDF_CACHE_TTL_SECONDS`         | `2592000`                                         | PDF 缓存保留时长（默认 30 天）                                 |
| `CAGELEDGER_ANIMAL_INSPECTION_IMAGES`      | `data/files/animal-inspections/reference-images/` | 巡检参考图目录                                                 |
| `CAGELEDGER_ANIMAL_INSPECTION_ATTACHMENTS` | `data/files/animal-inspections/attachments/`      | 巡检附件目录                                                   |
| `CAGELEDGER_REIMBURSEMENT_ATTACHMENTS`     | `data/files/reimbursements/attachments/`          | 报销单附件目录                                                 |

`CAGELEDGER_DATA_ROOT` 统一管理默认运行目录。各专项路径变量保留给独立挂载和历史部署使用，显式设置后优先级最高。

## 性能监控

| 变量                          | 默认值 | 用途                                     |
| ----------------------------- | ------ | ---------------------------------------- |
| `CAGELEDGER_SLOW_REQUEST_MS`  | `500`  | 超过该耗时的 HTTP 请求写入慢请求日志     |
| `CAGELEDGER_SLOW_DATABASE_MS` | `100`  | 超过该耗时的 SQLite 操作计入慢数据库操作 |

管理员可在“关于系统”页面查看请求延迟、缓存命中率、缓存淘汰、数据库操作延迟、锁错误以及 PDF 队列、生成耗时和缓存容量。运行指标保存在当前服务进程内，服务重启后重新计数；PDF 缓存文件按容量和保留时长自动清理。

## 运行日志

| 变量                                 | 默认值       | 用途                                                  |
| ------------------------------------ | ------------ | ----------------------------------------------------- |
| `CAGELEDGER_LOG_PERSISTENCE_ENABLED` | `true`       | 正常只写持久化文件；关闭后改为只写控制台              |
| `CAGELEDGER_LOG_DIR`                 | `data/logs/` | 日志目录，默认跟随数据根目录                          |
| `CAGELEDGER_LOG_MAX_BYTES`           | `10485760`   | 单份日志轮转阈值，默认 10 MiB，允许 64 KiB 至 100 MiB |
| `CAGELEDGER_LOG_FILE_COUNT`          | `5`          | 包含当前文件的总份数，允许 2 至 20 份                 |

默认保存 `runtime.jsonl` 及最多四份轮转文件，容量约 50 MiB，按容量轮转，不保证固定保留天数。
运行日志只有一个正常落点：启用持久化时写文件，控制台仅输出日志目的地提示；关闭持久化时只写控制台。
Compose 将持久化开关、容量和份数从 `.env` 传入容器。单独覆盖容器日志目录时，也要为该目录配置持久化挂载。
目录创建或文件写入失败时，控制台接管本条及后续运行日志，不中断业务；本次进程停止写文件，恢复磁盘或权限后重启服务重新启用。

日志覆盖请求结果、后台任务、数据库错误、文件处理、PDF/Word 导出、AI 和反馈同步、启动及未捕获异常。
业务审计继续保存操作者、业务实体及变更前后快照；运行日志保存诊断信息，不复制业务审计快照，也不写入 SQLite。
定位字段包含版本、进程、线程、请求 ID、耗时、异常类型、SQLite 错误码与代码文件/函数/行号；不写入 SQL 文本、绑定参数、异常原始消息、提示词、附件内容和令牌。
异步 PDF 任务保留发起请求 ID。慢SQL记录不可逆查询指纹与调用文件／函数／行号，不记录SQL或绑定参数；同一指纹跨请求线程一分钟限频。其他重复错误按线程、操作和错误类型一分钟限频，后续同类日志附带被抑制次数；原有性能计数与业务审计不受限频影响。

## 初始账号与系统信息

| 变量                        | 默认值               | 用途                 |
| --------------------------- | -------------------- | -------------------- |
| `CAGELEDGER_ADMIN_USERNAME` | `admin`              | 首次启动的管理员账号 |
| `CAGELEDGER_ADMIN_PASSWORD` | `admin123`           | 首次启动的管理员密码 |
| `CAGELEDGER_ORGANIZATION`   | 中山大学中山眼科中心 | 系统归属单位         |
| `CAGELEDGER_DEPARTMENT`     | 实验动物中心         | 系统归属部门         |
| `CAGELEDGER_DEVELOPER`      | `Hugo`               | 开发者展示信息       |
| `CAGELEDGER_CONTACT_EMAIL`  | `info@cellnucle.us`  | 联系邮箱             |
| `CAGELEDGER_LICENSE`        | `Apache-2.0`         | 许可证展示信息       |

生产初始化不会接受开发默认口令。账号已存在时，修改初始化环境变量不会修改账号密码或权限。

## 版本与更新检查

| 变量                              | 默认值         | 用途                                                                                |
| --------------------------------- | -------------- | ----------------------------------------------------------------------------------- |
| `CAGELEDGER_APP_VERSION`          | 构建注入       | 运行版本展示                                                                        |
| `CAGELEDGER_REVISION`             | 构建注入       | 构建 revision 展示                                                                  |
| `CAGELEDGER_REPOSITORY_URL`       | Gitea 仓库地址 | Release 和源码入口                                                                  |
| `CAGELEDGER_BRANCH`               | `main`         | 当前分支展示                                                                        |
| `CAGELEDGER_UPDATE_CHECK_ENABLED` | `false`        | 启用 Gitea 更新检查                                                                 |
| `CAGELEDGER_GITEA_TOKEN`          | 空             | 更新检查和反馈工单共用，基线 `read:repository`、`write:issue`，账号须可访问私有仓库 |

生产环境将 token 写入部署平台的密钥配置。`.env` 文件和 token 不进入版本库。
